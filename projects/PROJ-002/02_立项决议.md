## 二、技术可行性评审意见

### 2.1 委员 B（光学计量）

**肯定意见**：

1. 核心解算式 (3) 的推导在数学上是严密的。设两腔护罩区几何与流量相同，则 δ 与 α_p 在两式相减时同时消去，这不是近似、而是恒等消元。**这一点是本项目最扎实的部分**——它把一个"标定问题"转化成了"结构对称性问题"，而结构对称性是可以通过制造工艺保证并可验收的，标定漂移则不可。
2. α_p 被同时消去这一副产物意义重大：护罩气纯度不再是计量瓶颈。这直接解锁了自源护罩方案。
3. 基长比选型 3.0 的论证充分。委员会特别认可申报方**主动披露噪声放大因子 G = 1.58 这一代价**，并在指标 T-1 中把 LOD 目标从单腔的 2.2 ppb 放宽到 5.0 ppb，而非回避。

**质疑与要求**：

- **Q-B1**：式 (3) 隐含"两腔内的水分吸收线型完全一致"。若两腔压力有差异（例如并联歧管压降不同），线型展宽不同，ᾱ₁ 与 ᾱ₂ 不可直接线性联立。
  → **要求**：两腔池压差必须纳入考核项，建议控制在 ≤ 1.0 Torr（相对 500 Torr 即 0.2%），并在 S2 阶段实测给出压差对 α_s 的灵敏度系数。
- **Q-B2**：标准具条纹在两腔中不相关，会被 G = 1.58 放大。要求在 S2 明确条纹抑制措施的实测效果，而非仅列设计手段。
  → **要求**：给出条纹等效噪声（以 ppbv 计）的实测值，并纳入不确定度预算。

### 2.2 委员 C（流体与传热）

**肯定意见**：

1. δ 随护罩流量、池压、长期污染三重漂移的机理分析符合实际。委员会认同"δ 不可在线测量"是现有护罩式 CRDS 无法通过 MSA 的真实根因。
2. 采用**等长等阻并联**而非串联的判断正确。串联方案下游腔的样气已被上游腔壁吸附改变，无论如何配置都无法满足式 (3) 的同源前提。

**质疑与要求**：

- **Q-C1**：δ₁ = δ₂ 是全部方案的地基。申报方给出的保证手段（同批镜片、同模具扩散器、同规格 MFC）属于**工艺一致性保证**，但缺少**运行期验证手段**。若运行三个月后一只扩散器局部堵塞，δ₁ ≠ δ₂ 而系统无从察觉，将输出一个"看起来正常但已失准"的结果——这比直接报警更危险。
  → **要求（否决性）**：必须增加运行期的 Δδ 交叉验证能力，并作为 M2 里程碑的验收内容之一。
- **Q-C2**：两腔内径均取 12.0 mm 的设计意图应写明。委员 C 指出这不仅是为 δ 一致，更是为**面容比 S/V 一致**——壁面出气造成的水分背景在两腔中才会呈现为同一个 α_w，从而作为共模零点被零点标定吸收。
  → **要求**：在专利文件中将"两腔内径相同"作为独立的从属权利要求，并写明其双重技术效果。

### 2.3 委员 D（耐蚀材料）

**肯定意见**：

1. 放弃"耐蚀镜膜"路线（R1）的判断正确。高反膜的每一层附加保护层都直接抬高 1−R，与 CRDS 的灵敏度需求根本冲突；用流体护罩把腐蚀问题移出光学域是正确的层次划分。
2. Hastelloy C-22 + EP（Ra ≤ 0.13 μm）+ 60 °C 恒温的组合对 HCl/Cl₂/HBr 是成熟可靠的。

**质疑与要求**：

- **Q-D1**：BCl₃ 与 WF₆ 工况下的水解固体（H₃BO₃、WO₂F₂）沉积会同时污染扩散器与歧管，且**两侧沉积速率不可能完全相同**，这将直接破坏 δ₁ = δ₂。
  → **要求**：BCl₃ / WF₆ 工况在结题报告中单独列出适用性结论，不得与 HCl/Cl₂/HBr 混为一谈。若不达标，应明确限定为不推荐工况。
- **Q-D2**：耐酸型分子筛 3A 纯化器在 Cl₂ 中的容量衰减需实测，不得引用手册数据。90 天更换周期须有 6000 h 台架支撑。

### 2.4 委员 A（气体设备，主任委员）

1. 该模块的安装位置为 GC / VMB 的取样支路（side-stream），样气最终排入 Scrubber，**不回注主路**，安全边界清晰，与现有气柜的联锁逻辑兼容性好。
2. 样气消耗 250 sccm（含自源护罩分流 120 sccm）对特种气体而言并非小数目。要求在 S4 评估长期运行的气体成本，并在产品定义中给出"低耗模式"（降低护罩流量）的可行性——注意到式 (3) 已使结果与护罩流量无关，**低耗模式在计量上是无代价的，仅影响镜片寿命**，这是本方案的一个额外优势，应在结题报告中明确量化。

## 三、市场前景评审意见（委员 F）

1. **需求真实**：Fab 对腐蚀性气体的水分在线监测存在明确的合规与良率驱动，目前普遍依赖离线取样 + 定期送检，数据滞后 3~7 天，无法用于工艺关联分析。
2. **竞争格局**：CRDS 微量水分分析仪市场由 Tiger Optics、Picarro 等占据，但其产品主要面向**惰性/非腐蚀基底气**（N₂、Ar、He、H₂）。腐蚀性气体型号存在，但均以"镜片为耗材、定期更换"的模式销售，且未解决护罩稀释的计量准确度问题——这正是本项目的差异化空间。
3. **产品定位**：不与通用型分析仪正面竞争，定位为**GC/VMB 集成型模块**，随气柜销售，形成设备—模块绑定。
4. **风险**：客户对新计量原理的接受需要计量确认（MSA / Gage R&R）证据链，建议 S6 阶段的现场挂机数据按 Gage R&R 格式组织。

## 四、专利与 FTO 评审意见（委员 E）

### 4.1 现有技术检索结论

检索覆盖 CRDS 微量水分、腔镜护罩、多光程差分、气体采样池等主题，主要相关现有技术归纳如下：

| 类别 | 现有技术 | 与本项目的关系 |
|---|---|---|
| E-1 | 腔衰荡光谱测微量水分（基础原理） | 公知技术，不构成障碍，本项目不主张 |
| E-2 | 腔镜惰性气体护罩（mirror purge） | **公知技术**。本项目不单独主张护罩本身 |
| E-3 | 双腔差分吸收（一腔为参考腔充零气） | 结构上是双腔，但**参考腔不通样气**，护罩区贡献不可比，无法消 δ；解算式为简单相减而非式 (3) 的加权联立 |
| E-4 | 多光程池（Herriott / White）改变有效光程 | 改变的是同一腔内的反射次数，护罩区被反复穿越，2δ/L_eff 不随反射次数线性变化，无法建立式 (1)(2) 的线性方程组 |
| E-5 | 护罩流量标定 / 稀释因子出厂修正 | 属计划书中已否决的 R2 路线，是本项目要解决的对象 |
| E-6 | 自净化 / 在线纯化气路 | 用于供气纯化，未见用于"腔镜护罩气与样气同源"的记载 |

### 4.2 创造性落脚点认定

委员会认定，本项目的创造性**不在于**"用两个腔"或"用护罩"，而在于以下技术特征的**捆绑组合**：

- **(a)** 两衰荡腔基长不等，且 **L₁/L₂ ≥ 2**；
- **(b)** 两衰荡腔**内径相同、护罩喷嘴几何相同、护罩气流量相同**，使 δ₁ = δ₂ 成为可设计、可验收的结构约束；
- **(c)** 样气以**等长等阻并联**方式同源送入两腔（而非串联）；
- **(d)** 按 **α_s = (ᾱ₁L₁ − ᾱ₂L₂)/(L₁ − L₂)** 解算，使 δ 与 α_p 同时消元。

其中 **(b) + (d)** 的组合是新颖性与创造性的主要落脚点：现有技术即使公开了双腔结构，也没有动机去**刻意设计两腔的护罩边界层严格相等**——因为在现有技术的认知里，护罩稀释是"要标定掉的误差"，而非"要构造成共模量再消元的变量"。这一认知转变构成非显而易见性。

**(e)** 自源护罩（护罩气取自样气分流并经脱水后回注）是第二个独立的创造性落脚点，其非显而易见性在于：现有技术追求护罩气"越干越好"，而本方案因式 (3) 已消去 α_p，**放弃了对护罩气纯度的追求，转而追求基底气种一致性**——这是与现有技术相反的技术偏见克服。

### 4.3 FTO 风险评估

- 对 E-1 / E-2 / E-4 / E-5：本项目不主张这些技术本身，独立权利要求以 (a)~(d) 的组合限定，落入他人保护范围的风险**低**；
- 对 E-3：需在独立权利要求中明确"**两衰荡腔均通入来自同一取样源的被测样气**"，以在文字上与"参考腔充零气"的现有技术划清界限。**该限定为必要限定，不得省略**；
- 建议同步布局系列专利（分案/关联申请）P002-2 ~ P002-5，形成对自源护罩、并联歧管对称性判据、δ 健康度诊断、耐蚀采样池的外围包围。

**结论**：FTO 风险可控，创造性落脚点清晰且可辩护，**同意作为核心专利立项**。

## 七、决议结论

评审委员会经充分讨论与质询，认为：

1. 项目所针对的"护罩边界层不可标定稀释"是强腐蚀性气体 ppb 级水分在线计量的**真实且未被解决**的工程痛点；
2. 所提出的双不等基长腔差分解算式在数学上严密，且把标定问题转化为可制造、可验收的结构对称性问题，技术路径清晰；
3. 申报方对噪声放大 G = 1.58 这一代价的主动披露与指标折中，体现了工程判断的严肃性；
4. 与已有项目 PROJ-001 在被测量、计量原理、核心不确定量、消除手段四个维度均无重合，不构成重复立项；
5. FTO 风险可控，创造性落脚点清晰。

**表决结果：应到有表决权委员 6 人，实到 6 人，同意 6 票，反对 0 票，弃权 0 票。**

**决议：全票通过，同意立项。**

核定预算 628 万元，周期 2026-09-01 ~ 2028-02-29。附加要求 AR-1 ~ AR-9 与本项目计划书具有同等约束力，其中 **AR-3 为否决性条款**——M2 节点未建立运行期 Δδ 交叉验证机制的，项目转入整改，不得进入 S4 计量性能考核阶段。
