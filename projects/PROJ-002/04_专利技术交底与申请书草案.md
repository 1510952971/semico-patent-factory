## 一、技术领域

本发明涉及半导体特种气体品质在线监测技术领域，具体涉及一种安装于气柜（Gas Cabinet, GC）或阀门分配箱（Valve Manifold Box, VMB）取样支路上，用于测量 HCl、Cl₂、HBr、WF₆、NF₃ 等强腐蚀性特种气体中 ppb 量级水分含量的腔衰荡光谱（CRDS）检测装置及其测量方法。

## 二、背景技术

### 2.1 需求背景

在先进逻辑（3nm/N2 节点 GAA 环栅）与高层数 3D NAND（≥232 层）的刻蚀、清洗与金属化制程中，HCl、Cl₂、HBr、BCl₃、WF₆、NF₃ 等强腐蚀性气体被大量使用。这些气体中的微量水分会引发管路点蚀与金属污染、生成 AlCl₃·6H₂O / WOF₄ / H₃BO₃ 等固体产物堵塞喷淋头与泵口、并使等离子体解离路径漂移。业界对该类气体的水分规格已收紧至钢瓶出口 < 20 ppbv、使用点（POU）< 50 ppbv，且要求在线连续监测——因为离线取样时管路自身的吸附解吸即可引入 100 ppbv 量级的假信号。

### 2.2 现有技术及其缺陷

**（1）非光学传感器路线**：电容式（Al₂O₃/SiO₂）露点仪的敏感层在 HCl/HBr 中 3~8 周即化学中毒；电解式（P₂O₅）与 Cl₂/HBr 直接反应，寿命不足 2 周；QCM 涂层的吸湿位点被腐蚀气占据而丧失选择性。三者均不能在腐蚀性基底气中长期在线工作。

**（2）直接吸收光谱路线（FTIR / TDLAS）**：ppb 级水分在数十厘米光程内的吸光度约 10⁻⁶，低于直接吸收法的基线噪声两个数量级，灵敏度根本不足。

**（3）腔衰荡光谱（CRDS）路线**：CRDS 通过测量光在高反腔内的衰荡时间常数 τ 求取吸收系数

```
α = (1/c) · (1/τ − 1/τ₀)
```

其有效光程可达数十公里，噪声等效吸收系数可低至 10⁻¹¹ cm⁻¹ 量级，是唯一在灵敏度上满足 ppb 需求的路线。**因此，问题被收敛为：如何在强腐蚀性基底气中保住反射率 R > 99.998% 的腔镜。**

**（4）耐蚀镜膜方案的缺陷**：在高反膜外增镀 Y₂O₃ / AlF₃ 等耐蚀保护层，会直接抬高腔损耗。实测 1−R 由 1.5×10⁻⁵ 劣化至约 8×10⁻⁵，衰荡时间常数下降 5.3 倍，灵敏度损失使 ppb 检测不再可能；且在 HBr 工况下 200 h 仍出现膜层雾化。该路线与 CRDS 的灵敏度需求存在根本冲突。

**（5）腔镜惰性气体护罩方案及其致命缺陷（本发明要解决的对象）**：

现有技术普遍采用在腔镜内侧设置环形扩散器、持续吹入干燥惰性气体（通常为高纯 N₂）形成保护流的方式，将腐蚀性样气"顶"离镜面。该方法确有护镜之效，但引入了一个在 ppb 级计量中致命的系统误差：

CRDS 测得的是**腔内平均吸收系数**。设腔长为 L，两端护罩区各占轴向长度 δ、其吸收系数为 α_p，中部样气段吸收系数为 α_s，则实测值 ᾱ 满足

```
ᾱ · L = α_s · (L − 2δ) + α_p · 2δ                    …… (1)
```

由于 α_p ≪ α_s，实测值系统性低于真值，低估比例约为 2δ/L。而 **δ 并非常数**：

- δ 随护罩气流量变化：护罩流量 20 → 40 sccm/端时，δ 由 6.1 mm 变为 11.2 mm；
- δ 随腔内压力变化：池压 300 → 600 Torr 时，δ 再变化约 ±1.8 mm；
- δ 随扩散器与镜面的长期污染**单调漂移**：6000 h 后 δ 由 8.7 mm 漂移至 12.4 mm。

对 L = 420 mm 的腔而言，上述变化对应 −2.7% ~ −5.9% 的示值偏差，且长期漂移约 −1.8%/年、方向单一。

**关键在于：该误差无法通过标定消除。**标定时的护罩流量、池压与污染状态均与实际工况不同，而 δ 是一个埋藏在腔体内部、无法在线直接测量的量。现有技术或采用出厂固定稀释因子修正（因 δ 会漂移而失效），或采用示踪气反演 δ（示踪气污染样气，且示踪分子与水分子扩散系数不同、δ 不等价），均未真正解决问题。这正是护罩式 CRDS 迄今无法通过 Fab 计量确认（MSA / Gage R&R）的根本原因。

**（6）已有双腔方案的不适用性**：现有差分吸收型双腔装置中，第二腔为**充入零气的参考腔**，其内不通被测样气，故两腔的护罩区贡献不可比，δ 无从消去；其解算亦为简单相减而非加权联立。多光程池（Herriott / White 型）虽可改变有效光程，但光束在同一腔内反复穿越同一护罩区，2δ 在有效光程中的占比不随反射次数线性变化，无法建立可解的线性方程组。

### 2.3 现有技术的技术偏见

现有技术始终把护罩稀释视为"需要标定掉的误差"，因而其全部努力方向是**减小 δ、减小 α_p、精确标定 2δ/L**。在这一认知框架下，本领域技术人员没有动机去刻意构造两个护罩边界层严格相等的腔体——因为在他们看来 δ 是需要消灭的对象，而不是需要构造为共模量再予消元的变量。同理，现有技术追求护罩气"越干越好"，也没有动机去把护罩气取自被测样气本身。

## 三、发明内容

### 3.1 本发明要解决的技术问题

1. **主问题**：如何在保留腔镜护罩（护镜必需）的前提下，使腔衰荡水分测量结果在**原理上**与护罩边界层厚度 δ 无关，从而消除 δ 随护罩流量、腔压与长期污染漂移所引起的、不可标定的系统误差（现有技术为 3.3% 跨工况极差、−1.8%/年漂移）。
2. **次问题一**：如何消除护罩气自身残余水分 α_p 对测量结果的影响，从而解除"护罩气纯度"对计量准确度的约束。
3. **次问题二**：当护罩气与样气基底气种不同时，二者的压力展宽系数不同，导致护罩段与样气段的吸收线型不一致，破坏式 (1) 的线性叠加前提（实测引入 0.79% 附加偏差）。如何消除该线型失配。
4. **次问题三**：上述方案的成立依赖两腔护罩边界层严格相等这一结构对称性。若运行期一侧扩散器非对称退化，装置将输出"看似正常但已失准"的结果。如何在运行期在线验证该对称性并在其破坏时主动报警。

### 3.2 技术方案

#### 3.2.1 核心原理：δ 与 α_p 的恒等消元

本发明设置**两只被测样气来自同一取样源、内径相同、护罩扩散器出流通道几何相同、护罩气流量相同，但腔长不等**的衰荡腔，腔长分别为 L₁ 与 L₂（L₁ > L₂，且 L₁/L₂ ≥ 2）。

由于两腔的护罩射流结构、护罩流量、腔内压力、被测样气组分与浓度均相同，两腔的护罩边界层厚度相等（δ₁ = δ₂ = δ），护罩区吸收系数亦相等（α_p1 = α_p2 = α_p）。对两腔分别写出式 (1)：

```
ᾱ₁ · L₁ = α_s · (L₁ − 2δ) + α_p · 2δ                 …… (2)
ᾱ₂ · L₂ = α_s · (L₂ − 2δ) + α_p · 2δ                 …… (3)
```

(2) − (3)，右端含 δ 的项与含 α_p 的项**同时恒等抵消**：

```
ᾱ₁L₁ − ᾱ₂L₂ = α_s · (L₁ − L₂)

              ᾱ₁L₁ − ᾱ₂L₂
      α_s = ─────────────────                        …… (4) 【核心解算式】
                L₁ − L₂
```

被测样气的水分浓度由 c_s = α_s / k_H2O 得出（k_H2O 为该吸收线在测量温度、压力下的单位浓度吸收系数）。

**式 (4) 的关键性质**：结果中不含 δ，也不含 α_p。这不是近似，是恒等消元。因此：

- 护罩流量可以任意调整（甚至为了省气而大幅降低），不影响测量准确度；
- 腔内压力波动不再通过 δ 影响结果；
- 扩散器与镜面的长期污染导致 δ 漂移，只要两腔同步（共模），结果不受影响；
- **护罩气不需要很干**——这直接解锁了 3.2.3 的自源护罩方案。

#### 3.2.2 结构参数选型：基长比的两难与最优点

由式 (4) 作误差传递，两腔测量噪声向结果的传递权重分别为 L₁/(L₁−L₂) 与 L₂/(L₁−L₂)，噪声放大因子为

```
G = √[ (L₁/(L₁−L₂))² + (L₂/(L₁−L₂))² ]              …… (5)
```

G 随 L₁/L₂ 增大而单调减小，似乎基长比越大越好。但另一方面，为使式 (4) 的分子 (ᾱ₁L₁ − ᾱ₂L₂) 有足够信噪比，两腔的稀释率 2δ/L₁ 与 2δ/L₂ 必须显著不同；同时短腔的衰荡时间常数 τ₀₂ = L₂/[c(1−R)] 不能过小，否则指数拟合精度崩溃。二者构成相反约束：

| L₁/L₂ | G | 短腔稀释率 2δ/L₂ | 短腔 τ₀₂ | 评价 |
|---|---|---|---|---|
| 1.5 | 3.61 | — | — | 噪声放大过大 |
| 2.0 | 2.24 | 8.3%（L₂ = 210 mm） | 46.7 μs | 可用，偏保守 |
| **3.0** | **1.58** | **12.4%（L₂ = 140 mm）** | **31.1 μs** | **最优** |
| 6.0 | 1.22 | 24.9%（L₂ = 70 mm） | 15.6 μs | 拟合精度不足，机械稳定性差 |

本发明优选 **L₁/L₂ = 2.5 ~ 4.0**，最优选 **L₁ = 420 mm、L₂ = 140 mm（比值 3.0）**。此时长短腔稀释率分别为 4.14% 与 12.43%，相差 8.3 个百分点，差分信号充分；G = 1.58 的噪声代价换取 3.3% → 0.22% 的准确度改善。

#### 3.2.3 自源护罩（解决次问题二）

本发明将护罩气**取自被测样气本身**：由样气主路分流一股，经耐酸型深度脱水纯化器（分子筛 3A + 耐酸粘结剂）脱水后，回注两腔的全部环形扩散器作为护罩气。

其可行性完全依赖于式 (4) 已消去 α_p——护罩气"没有脱到极干"（实测出口 0.31 ppbv，运行 6000 h 后升至 11.2 ppbv）对结果无影响。其技术效果为：

- 护罩段与样气段的基底气种完全相同，压力展宽系数一致，式 (2)(3) 的线型一致前提严格成立，消除 0.79% 的线型失配偏差；
- 界面无组分梯度，护罩边界层稳定性提升，δ 短时抖动由 ±0.9 mm 降至 ±0.2 mm；
- 不引入第二气源与第二套安全联锁，不稀释样气基底；
- 纯化器更换判据由"出口水分规格"改为"α_p > 50 ppbv"（该阈值仅由 δ 反演精度决定），更换周期由 90 天延长至 240 天。

**该方案克服了"护罩气越干越好"的技术偏见**：本发明放弃对护罩气纯度的追求，转而追求基底气种一致性。

#### 3.2.4 结构对称性的运行期在线验证（解决次问题三）

本发明设置**加湿诊断源**（恒温渗透管，输出约 2 ppmv）、**诊断气/样气切换阀**与**护罩直测隔离阀**，建立两级自检：

**一级自检——α_p 直测（周期 24 h，耗时约 3 min）**：关闭样气流量控制器、开启护罩直测隔离阀，令护罩气充满两腔全长（此时 2δ = L），两腔应有 ᾱ₁ = ᾱ₂ = α_p。该步骤同时给出：(i) α_p 实测值，供二级自检使用；(ii) |ᾱ₁ − ᾱ₂| 作为**不依赖任何模型的零假设检验**，直接检验两腔光学与解算链路的一致性；(iii) 纯化器容量衰减曲线。

**二级自检——交替非对称护罩调制（AAPM，周期 6 h，耗时 90 s）**：切入 2 ppmv 诊断气（浓度足够高以保证反演信噪比），先在对称态由式 (4) 求 α_s，再依次单独提高一只腔的护罩流量，分别由下式反演各腔的边界层厚度：

```
        L₁ (α_s − ᾱ₁)                    L₂ (α_s − ᾱ₂)
2δ₁ = ─────────────────        2δ₂ = ─────────────────      …… (6)
          α_s − α_p                        α_s − α_p
```

输出 Δδ = δ₁ − δ₂，并给出残余偏差的定量预测：

```
ε = −2Δδ / (L₁ − L₂)                                 …… (7)
```

实测 Δδ = 0.31 mm，式 (7) 预测 ε = −0.221%，与实测示值偏差 −0.22% 吻合至第三位有效数字。设 Δδ > 0.8 mm 触发一级报警、Δδ > 1.5 mm 触发失准锁定并停止输出浓度值。

#### 3.2.5 保证 δ₁ = δ₂ 的结构约束（可制造、可验收）

本发明将"标定问题"转化为"结构对称性问题"，因此对称性必须是可设计、可制造、可验收的：

| 约束 | 数值 | 技术作用 |
|---|---|---|
| 两腔内径相同 | 均为 12.0 mm | (i) 护罩射流与主流的动量比、雷诺数一致，保证 δ₁ = δ₂；(ii) 面容比 S/V 相同，壁面出气水分背景 α_w 在两腔中相等，作为共模量被零点标定吸收 |
| 扩散器同模具同批次 | 出流均匀性 ≤ ±3% | 保证射流出口速度剖面一致 |
| 腔镜同镀膜批次 | 1−R = 1.50 与 1.52 ×10⁻⁵ | 镜面粗糙度与曲率一致，边界层附着条件一致 |
| 护罩流量一致 | 四只 MFC 出厂互校至 ±0.3% | 直接决定 δ |
| 样气等长等阻并联 | 流导差 ≤ 1.5%，管长差 ≤ 2 mm | 保证两腔样气浓度、压力、流速同态；**必须并联而非串联**——串联时下游腔样气已被上游腔壁吸附改变 |
| 两腔压差 | ≤ 1.0 Torr（实测 0.42 Torr） | 保证两腔吸收线型一致 |
| 全流路恒温 | 60.00 ± 0.05 °C | 抑制壁面吸附拖尾 |
| 腔体材料与表面 | Hastelloy C-22，电解抛光 Ra ≤ 0.13 μm | 耐腐蚀 + 低吸附 |

### 3.3 有益效果（均有实测数据支撑）

**效果一：护罩相关系统偏差降低 15 倍，且跨工况几乎不变。**
在 1.000 ppmv 标气、HCl 6N 基底下，护罩流量 {20, 30, 40} sccm × 池压 {300, 500, 600} Torr 共 9 个工况点：

| | 单光程（仅长腔） | 本发明（差分） |
|---|---|---|
| 示值范围 | 0.941 ~ 0.973 ppmv | 0.9975 ~ 0.9980 ppmv |
| 跨工况极差 | **3.3%** | **0.05%** |
| 相对真值偏差 | −2.7% ~ −5.9%（不可标定） | −0.22%（恒定，可作零位吸收） |

**效果二：护罩气残余水分被恒等消去。**
故意旁路护罩纯化器，使护罩气水分由 0.31 ppbv 升至 480 ppbv（约样气浓度之半）：单光程示值由 0.959 跃升至 0.979 ppmv（+2.1%），而本发明差分示值由 0.9978 变为 0.9974 ppmv（变化 0.04%，在噪声内）。

**效果三：长期漂移降低 15 倍。**
HCl 6N、60 °C 连续 6000 h：Δδ 由 0.31 mm 增至 0.48 mm，残余偏差由 −0.22% 变为 −0.34%，折合 **0.12%/年**；同期单光程方案为 **1.8%/年**且单调。

**效果四：自源护罩消除线型失配偏差 0.79%。**
同条件下以高纯 N₂ 作护罩气时差分示值 0.9899 ppmv（偏差 −1.01%），改为自源护罩后 0.9978 ppmv（偏差 −0.22%）。

**效果五：护罩流量与计量准确度解耦，可实施"低耗模式"。**
护罩流量由 30 sccm/端降至 12 sccm/端（δ 由 8.7 mm 降至 4.2 mm），差分示值仅变化 +0.09%（在 1σ = 0.24% 内不可分辨），样气总消耗由 248 sccm 降至 176 sccm（降 29%）。而单光程方案下护罩流量每变化 10 sccm 即引入约 1.2% 示值偏差，不存在此选择余地。

**效果六：护罩使腔镜寿命提升 30 倍以上，且本发明不为此付出准确度代价。**
HCl 6N、60 °C：有护罩时 6000 h 后 1−R 由 1.50 升至 1.90×10⁻⁵，检出限由 3.5 劣化至 4.4 ppbv（+25.7%）；无护罩对照组 196 h 即失效（1−R 升至 9.8×10⁻⁵，检出限 27 ppbv，镜面 SEM/EDS 检出 Fe、Ni、Cl 雾状沉积）。

**效果七：具备运行期自检能力，失准时报警而非静默漂移。**
在 BCl₃ 工况摸底试验中（水解产物 H₃BO₃ 在扩散器出口结晶），AAPM 于第 612 h 检出 Δδ = 0.83 mm 并触发一级报警，第 980 h 触发失准锁定；若无该机制，装置将在 800 h 时静默输出偏低 1.16% 的结果。

**效果八：计量性能。**
检出限 3.5 ppbv（3σ，60 s）、8.6 ppbv（3σ，10 s）；量程 3.5 ppbv ~ 20 ppmv；t₉₀ = 108 s；合成扩展不确定度 U = 1.11%（k = 2，不含标气溯源）；外漏率 6.2×10⁻¹¹ atm·cc/s He；现场 90 天挂机 %GRR = 8.7%，ndc = 14。

**代价的如实披露**：由式 (5)，本发明的噪声放大因子 G = 1.58，检出限由单腔模式的 2.2 ppbv 劣化至 3.5 ppbv。在 Fab 的 POU < 50 ppbv 规格下，准确度而非检出限是瓶颈，该交换是有利的。

**11.** 一种腐蚀性气体微量水分在线检测的护罩边界层消元方法，其特征在于，包括以下步骤：

**S1** 提供腔长分别为 L₁ 与 L₂ 的第一衰荡腔与第二衰荡腔，且 L₁ > L₂、L₁ / L₂ ≥ 2；在两腔的每一腔镜的腔内侧设置出流通道几何相同的环形护罩扩散器；

**S2** 将来自同一取样源的同一被测样气经流导相等的两条支路，以并联方式同时通入所述第一衰荡腔与所述第二衰荡腔；

**S3** 以相等的流量向所述第一衰荡腔与所述第二衰荡腔的各环形护罩扩散器供给护罩气，使两腔内的护罩气边界层轴向厚度 δ 相等、护罩气水分吸收系数 α_p 相等；

**S4** 分别测量所述第一衰荡腔与所述第二衰荡腔的衰荡时间常数，得到两腔的平均吸收系数 ᾱ₁ 与 ᾱ₂；

**S5** 按 α_s = (ᾱ₁·L₁ − ᾱ₂·L₂) / (L₁ − L₂) 计算被测样气段的水分吸收系数，使 δ 与 α_p 在计算中同时被消去；

**S6** 由 α_s 及该吸收线在测量温度与压力下的单位浓度吸收系数，换算得到被测样气的水分浓度。

**12.** 根据权利要求 11 所述的方法，其特征在于，步骤 S3 中所述护罩气自所述被测样气中分流并经脱水后回注，使护罩气与被测样气的基底气种相同。

**13.** 根据权利要求 11 所述的方法，其特征在于，还包括边界层对称性在线验证步骤：

**S7-1** 将所述样气歧管入口切换至水分浓度高于被测样气规格上限的诊断气；

**S7-2** 在两腔护罩气流量相等的对称态下，按步骤 S5 求得 α_s；

**S7-3** 保持一腔护罩气流量不变、单独提高另一腔的护罩气流量，交替进行，分别按下式反演两腔的边界层轴向厚度：

```
2δ₁ = L₁·(α_s − ᾱ₁) / (α_s − α_p)      2δ₂ = L₂·(α_s − ᾱ₂) / (α_s − α_p)
```

**S7-4** 计算 Δδ = δ₁ − δ₂ 及残余偏差 ε = −2Δδ / (L₁ − L₂)；当 |Δδ| 超过第一阈值时输出报警，当 |Δδ| 超过大于所述第一阈值的第二阈值时锁定并停止输出水分浓度值。

**14.** 根据权利要求 13 所述的方法，其特征在于，步骤 S7-3 中所述 α_p 由下述护罩气直测步骤获得：关闭样气流量控制器并开启护罩直测隔离阀，令护罩气充满两腔全部腔长，取两腔测得的平均吸收系数为 α_p；并且，以两腔该测量值之差 |ᾱ₁ − ᾱ₂| 是否超过设定限值，作为两腔光学与解算链路一致性的判据。

**15.** 根据权利要求 14 所述的方法，其特征在于，以所述 α_p 的实测值超过设定阈值，而非以护罩气水分浓度低于某一规格值，作为所述脱水纯化器的更换判据。

**16.** 根据权利要求 11 所述的方法，其特征在于，还包括低耗护罩模式：在保持两腔护罩气流量相等的前提下，将护罩气流量同步降低至标准值的 30% ~ 50%，此时被测样气水分浓度的测量结果不受影响，仅腔镜使用寿命缩短。

- 9 工况矩阵（护罩流量 {20,30,40} sccm × 池压 {300,500,600} Torr）示值极差 0.05%，对照单光程模式 3.3%；
- 检出限 3.5 ppbv（3σ，60 s）/ 8.6 ppbv（3σ，10 s）；
- t₉₀ = 108 s；U = 1.11%（k = 2）；
- 6000 h 连续运行后 Δδ 增至 0.48 mm，偏差变为 −0.34%，折合 0.12%/年；1−R 升至 1.90×10⁻⁵，检出限劣化至 4.4 ppbv；
- 现场 90 天挂机 %GRR = 8.7%，ndc = 14，通过客户计量确认。

**自检执行**：AAPM 每 6 h（诊断气 2.0 ppmv，90 s），δ 反演分辨率 0.10 mm；α_p 直测每 24 h（3 min）。6000 h 内 |ᾱ₁ − ᾱ₂| 始终 ≤ 0.9 ppbv，未触发报警。

### 实施例 2：WF₆ 5N 使用点监测（有条件适用配置）

**应用场景**：钨 CVD 设备 POU 前 VMB 取样点。WF₆ 遇痕量水生成 WO₂F₂ 固体，会在烧结扩散器孔隙内缓慢沉积，且两端沉积速率不等，直接威胁 δ₁ = δ₂ 的前提。

**配置差异（相对实施例 1）**：

| 项目 | 调整 | 理由 |
|---|---|---|
| 基长比 | L₁ = 420 mm，L₂ = 120 mm（比值 3.5） | 提高比值使 G 由 1.58 降至 1.44，为 Δδ 增大后的偏差留出余量 |
| AAPM 周期 | 6 h → **2 h** | 沉积速率快，需更密的对称性监控 |
| 护罩流量 | 40 sccm / 端（较标准提高） | 抬高射流动量，抑制固体向孔隙深处渗入 |
| 维护动作 | 每 1000 h 执行 60 sccm × 30 min 干燥 N₂ 反吹再生 | 清除孔隙浅层沉积 |
| Δδ 报警阈值 | 0.8 mm → **0.6 mm** | 与提前维护策略匹配 |

**运行结果**：1500 h 台架试验中，未执行反吹时 Δδ 由 0.33 mm 增至 0.71 mm（残余偏差 −0.51%，超出 0.5% 限值）；执行上述维护策略后，Δδ 在 1500 h 内维持 ≤ 0.55 mm（残余偏差 ≤ 0.39%），满足要求。

**结论**：WF₆ 工况判定为**有条件适用**，须在产品手册中明示上述维护要求。

**反例说明（BCl₃，不推荐工况）**：BCl₃ 水解产物 H₃BO₃ 在 60 °C 下于扩散器出口结晶（SEM/EDS 确认 B、O 特征峰），反吹无法去除。800 h 试验中 Δδ 增至 1.62 mm（残余偏差 −1.16%）。本发明的自检机制在第 612 h（Δδ = 0.83 mm）即触发一级报警、第 980 h 触发失准锁定——**装置的行为是报警并停止输出，而非静默输出偏低 1.16% 的结果**。该工况判定为不推荐，列入规格书限制条款。

### 实施例 3：NF₃ 5N 小型化 POU 变体（比例缩放实施例）

**应用场景**：干法清洗（chamber clean）设备的 NF₃ POU 点，安装空间受限（可用高度 < 300 mm），规格要求 H₂O < 200 ppbv（较宽松）。

**配置**：

| 项目 | 参数 | 说明 |
|---|---|---|
| 第一衰荡腔 | L₁ = 210.00 mm，内径 12.0 mm | 长度减半 |
| 第二衰荡腔 | L₂ = 70.00 mm，内径 12.0 mm | 保持基长比 3.0 |
| 衰荡时间常数 | τ₀₁ = 46.7 μs，τ₀₂ = 15.6 μs | 短腔拟合精度下降 |
| 护罩流量 | 18 sccm / 端 | 小腔适配，实测 δ = 6.1 mm |
| 稀释率 | 2δ/L₁ = 5.81%，2δ/L₂ = 17.43% | 差分信号更强 |
| 样气流量 | 60 sccm，入口总取样 138 sccm | — |
| 平均时间 | 120 s | 补偿短腔拟合噪声 |

**运行结果**：检出限 14 ppbv（3σ，120 s）；9 工况示值极差 0.11%；实测 Δδ = 0.28 mm，残余偏差 ε = −2×0.28/140 = **−0.40%**。

**该实施例揭示的设计规律**：由式 (7)，残余偏差反比于 (L₁ − L₂)。腔体整体缩短一半时，即使 Δδ 保持不变，残余偏差也会**加倍**。因此小型化变体必须以更严格的对称性制造公差（本例要求 Δδ ≤ 0.30 mm，而实施例 1 仅需 ≤ 0.55 mm）或更宽松的准确度规格来匹配。本实施例的准确度规格（< 200 ppbv）足以容纳 −0.40% 的残余偏差。

**本实施例证明**：本发明的原理与结构可按比例缩放，但 (L₁ − L₂) 是准确度的直接杠杆，缩放时必须同步收紧对称性公差——这一定量关系由式 (7) 明确给出，构成本发明可实施性的完整指导。

## 八、FTO 声明与创造性论证要点

**本发明不主张、亦不落入以下公知技术**：腔衰荡光谱测量微量水分的基本原理；腔镜惰性气体护罩本身；多光程池（Herriott / White）；差分吸收型双腔（一腔为充零气的参考腔）；护罩稀释因子的出厂标定修正。

**创造性论证的落脚点**：

1. **组合的非显而易见性**：现有技术把护罩稀释视为"要标定掉的误差"，其全部努力方向是减小 δ、减小 α_p、精确标定 2δ/L。在这一认知框架下，本领域技术人员**没有动机**去刻意设计两个护罩边界层严格相等的腔体——因为 δ 在其看来是消灭对象，而非需要构造为共模量再予消元的变量。本发明的技术贡献在于这一**认知转向**：把不可标定的标定问题，转化为可制造、可验收、可在线自检的结构对称性问题。

2. **权利要求 1 中特征 (c) 的划界作用**："通入两腔的是来自同一取样源的同一被测样气，且样气歧管两支路流导相等"这一限定，在文字上与"参考腔充零气"的现有技术彻底划清界限；并联而非串联的限定，则排除了串联时下游腔样气被上游腔壁吸附改变的构型。该限定为必要限定。

3. **权利要求 3 / 12 的技术偏见克服**：现有技术追求护罩气纯度越高越好，而本发明因式 (4) 已消去 α_p，**主动放弃**对护罩气纯度的追求，转而追求基底气种一致性。实验证明：护罩气水分由 0.31 ppbv 恶化至 480 ppbv 时，本发明示值仅变化 0.04%，而单光程方案变化 +2.1%。这是与现有技术相反方向的技术选择，且有确凿的有益效果支撑。

4. **预料不到的技术效果**：(i) 护罩气纯化器的更换周期由 90 天延长至 240 天，耗材成本降 62%——这是消去 α_p 的间接后果，非本领域技术人员所能预期；(ii) 护罩流量与计量准确度完全解耦，使"低耗模式"成为可能（省气 29% 而准确度无损），而在现有技术中护罩流量每变化 10 sccm 即引入约 1.2% 偏差，根本不存在此自由度。
