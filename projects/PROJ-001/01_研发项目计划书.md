## 一、项目背景与痛点

### 1.1 制程侧驱动力

当前 3nm/N2 GAA 逻辑器件与 232 层以上 3D NAND 的量产，其关键薄膜（High-k 栅介质 HfO₂、金属栅 TiN/TiAlC、间隔层 SiO₂/SiN、W 填充成核层）已全面转向 ALD，而高深宽比（AR > 60:1）沟道刻蚀转向 ALE。二者的共同物理本质是**"自限制表面反应"**，其工艺窗口对**单脉冲前驱体剂量（dose，单位 mol/pulse）**的重复性提出了传统连续流供气无法满足的要求：

- ALD 单周期沉积厚度 GPC（Growth Per Cycle）约 0.05~0.12 nm。3D NAND 高深宽比孔内要实现饱和覆盖，剂量必须超过饱和阈值 n_sat；但过量剂量会造成 CVD 寄生沉积、颗粒与前驱体浪费（金属有机源单价 8,000~35,000 元/kg）。工艺窗口实为 n_sat ≤ n ≤ 1.5·n_sat。
- 500 循环以上的堆叠工艺中，剂量若存在 0.1%/循环的单向漂移，累积厚度偏差可达 5% 以上，直接击穿 WIW（Within-Wafer）/ WTW（Wafer-to-Wafer）厚度均匀性预算（业界 3σ ≤ 1%）。

### 1.2 现有供气技术的三重缺陷

**（1）热式质量流量控制器（Thermal MFC）不适用于毫秒级脉冲**
热式 MFC 依靠毛细分流管的热边界层温度差测流，其传感器时间常数 τ 典型为 0.6~1.5 s，整机 0~100% 阶跃稳定时间 ≥ 500 ms。当工艺要求 10~50 ms 脉冲时，MFC 输出全程处于未建立的暂态，示值不代表实际通过量，**测量与控制同时失效**。压力式（Pressure-Based）MFC 借助临界流文氏管可将响应压缩至 ~100 ms，但仍无法覆盖 10 ms 量级，且要求上下游压比 > 2，对低蒸汽压前驱体（如 HCDS 25 °C 饱和蒸汽压仅 ~4 Torr）不成立。

**（2）"定容充放"（Dose Volume / Fill-and-Push）方案存在有效容积漂移的开环缺陷**
业界现行主流的规避手段是取消流量计，改用一个已知几何容积 V₀ 的小腔体：上游阀充填至压力 P₁，关闭后经下游阀泄放至工艺腔，以 n = P₁·V₀/(R·T) 作为标称剂量。该方案响应快，但为**纯开环标定**，其致命弱点是：

- **内壁吸附层导致有效容积漂移**：TMA、TDMAT、HCDS、Hf(NMe₂)₄ 等前驱体对 316L EP 内壁存在化学吸附与多层物理吸附，长期运行后腔壁形成 5~50 nm 量级的吸附/寡聚沉积层。以 V₀ = 5 cm³、内表面积 ~22 cm² 计，30 nm 沉积层直接侵占 6.6×10⁻⁵ cm³（相对量 1.3×10⁻³），叠加表面粗糙度放大因子（EP 面实际比表面 ~1.4）后，有效容积 V_eff 的年漂移实测可达 0.8%~2.5%。
- **可逆吸附/脱附造成的剂量系统偏差**：每一次充放循环，腔壁会"扣留"一部分前驱体分子（吸附）并在下一次低压阶段释放（脱附），该项 n_ads 与压力、温度、腔壁历史状态相关，典型占标称剂量的 0.5%~3%，且随腔壁老化单向变化。
- 现有产品只能靠**定期离线拆机、氦质谱＋气体膨胀法在计量室重标 V₀**，单次停机 6~8 小时，且拆装破坏颗粒洁净度，重新 Qual 又需 2~3 片 monitor wafer。

**（3）前驱体冷凝造成的"隐性剂量丢失"**
低蒸汽压前驱体在腔体或阀座局部冷点冷凝为液滴，既不计入压降计算，又会在后续脉冲中不可控地闪蒸，形成剂量尖峰与颗粒。现有模块普遍只对腔体做单点伴热，阀体—腔体—管路结合部的"热桥空洞"温差可达 8~15 °C。

### 1.3 本项目要解决的核心问题

> 在不拆机、不停产的前提下，使定容剂量腔的**有效容积 V_eff 与吸附偏差 n_ads 成为在线可测、可补偿的量**，从而把"开环定容供气"升级为**"逐脉冲闭环剂量供气"**，并在结构上根除冷凝与颗粒源。

### 3.2 核心技术路线（三条主线）

#### 路线 A：逐脉冲剂量计量闭环（Per-Pulse Dose Metering, PPDM）

单个供气脉冲的完整时序（总周期 ≥ 25 ms）：

| 阶段 | 时长 | 阀状态 | 动作 |
|---|---|---|---|
| S1 充填 | 3~50 ms | V1 开，V2 关 | 由源侧充填剂量腔至压力 P_hi |
| S2 平衡 | 5~20 ms | 全关 | 等待气体温度与腔壁热平衡，采样得 P₁、T₁（10 kHz 采 50~200 点取尾段均值） |
| S3 泄放 | 5~500 ms | V1 关，V2 开 | 向工艺腔泄放（工艺腔压力 ≤ 3 Torr，多处于阻塞流） |
| S4 回稳 | 5~20 ms | 全关 | 采样得 P₂、T₂ |

实际剂量：

```
n_k = (V_eff/R) · [ P₁/(Z₁·T₁) − P₂/(Z₂·T₂) ] − n_ads(P₁,P₂,T)
```

其中 Z 为压缩因子（低压下 → 1，对高蒸汽压有机源在 100 Torr 以上按 Peng-Robinson 修正）。控制器对 n_k 与目标 n_set 之差做增量式 PI 调节，修正下一脉冲的 S1 充填时长（或 P_hi 设定点），实现**每一个脉冲都被独立测量并反馈**——这是与开环定容法的根本区别。

#### 路线 B：在线容积自校准（In-situ Volume Self-Calibration, IVSC）—— 核心创新

采用**气体膨胀法（Sieverts 法）**，以内部参考腔 Vr(150) 作为传递标准，在晶圆交换窗口（≥ 3 s）内自动执行：

| 步骤 | 阀状态 | 测量 |
|---|---|---|
| C1 抽空 | V2 开、V3 开，接工艺腔真空 | V₀ 与 Vr 同抽至 P₀₀ ≤ 0.01 Torr |
| C2 隔离 | V3 关、V2 关 | — |
| C3 充参考腔 | V4 开 → 经旁路仅充 Vr（专用微管路） | Ar 充至 P_r0 ≈ 80 Torr，恒温平衡 200 ms，记 P_r0、T_r |
| C4 膨胀 | V3 开 | Ar 由 Vr 膨胀入 V₀，平衡 400 ms |
| C5 读数 | 全关 | 记平衡压力 P_f、温度 T_f |

由质量守恒（Ar 在 150 °C、80 Torr 下不吸附，Z ≈ 1）：

```
V_eff = Vr · (P_r0 − P_f) / (P_f − P₀₀) · (T_f/T_r)
```

**关键设计**：选用 **Ar 而非 N₂** 作为校准介质——Ar 在 EP 不锈钢与前驱体沉积层上的吸附焓 < 10 kJ/mol，150 °C 下覆盖度 < 10⁻⁴ ML，可视为完全非吸附；而 N₂ 在含金属有机残留的表面存在弱化学吸附，会引入 0.05%~0.2% 的系统偏差。

不确定度预算（k=2）：Vr 溯源 0.05 %，CDG 线性度 0.05 %，温度不均 ±0.5 °C 引入 0.06 %，压力读数噪声 0.03 %，合成 **U ≈ 0.11 %**，满足 T-04 的 0.15 % 目标。

#### 路线 C：吸附偏差在线分离（Adsorption Bias Separation, ABS）

即使 V_eff 已知，前驱体在腔壁的可逆吸附仍使"压降换算剂量"系统性偏高（吸附量未随气流带出）。本项目采用**双温调制法**分离该项：

在同一充填压力 P₁ 下，令夹套温度在 T_a（如 150 °C）与 T_b（如 165 °C）之间切换，各测一次平衡压力。若腔内总物质量 n_tot 相同，则气相物质量差即为吸附量差：

```
Δn_ads = n_gas(T_b) − n_gas(T_a) = (V_eff/R)·P₁·(1/T_a − 1/T_b) 之偏离量
```

拟合 Langmuir 等温式 θ = K(T)·P/(1+K(T)·P)，K(T) = K₀·exp(ΔH_ads/RT)，由两温点解出 ΔH_ads 与饱和吸附量 n_m（对应腔壁有效吸附位密度），进而在任意工况下实时计算 n_ads(P,T) 并从 n_k 中扣除。该标定每 2000 循环或每次换源后执行一次，耗时 ≤ 60 s。

#### 路线 D：防冷凝与低颗粒结构设计（支撑性）

- **单调升温梯度**：源（T_s）→ 管路（T_s + 2 °C/m）→ V1 阀体（T_s + 10 °C）→ 剂量腔（T_s + 15 °C）→ V2 阀体（T_s + 18 °C）→ 至工艺腔法兰（T_s + 20 °C）。全程无冷点，冷凝风险归零。
- **阀体—腔体一体化锻造**：V1/V2 阀座直接加工于剂量腔本体锻件上，取消 VCR 接头及其密封垫圈，消除"热桥空洞"与垫圈微腔死区，同时减少 4 处潜在漏点与颗粒源。
- **导流锥 111**：入口射流经导流锥沿腔壁形成附壁螺旋流，CFD 目标——腔内 95 % 体积的置换时间 ≤ 8 ms，角落回流区体积 ≤ 0.8 % V₀。
- **隔膜与阀座配对**：Hastelloy C-22 隔膜 + PCTFE 阀座（≤ 150 °C）/ Vespel SP-1 阀座（> 150 °C）；隔膜表面加 1.5 μm 无电解镀 Ni-P + Cr₂O₃ 复合钝化，抑制 HBr/Cl₂ 环境下的晶间腐蚀与磨屑生成。

### 3.3 攻关难点与对策

| 难点 | 风险 | 对策 |
|---|---|---|
| D1：CDG 在 150 °C 恒温下的零点漂移（0.02 Torr/月）会直接污染小剂量测量 | 高 | 每次 IVSC 的 C1 抽空阶段（P₀₀ ≤ 0.01 Torr）顺带执行 CDG 零点重置；双量程 CDG 交叉校验 |
| D2：压电阀在 200 °C 下叠堆退极化与推力衰减 | 高 | 采用高居里点 PZT（Tc > 320 °C）+ 阀体与叠堆之间设 12 mm 陶瓷隔热柱，叠堆实际工作温度 ≤ 90 °C；行程闭环（内置应变片）补偿衰减 |
| D3：S2 平衡阶段的热弛豫时间不足导致 P₁ 读数偏低（绝热充填后气体温度高于壁温） | 中 | 导流锥 111 增强壁面对流换热，实测热弛豫时间常数目标 ≤ 4 ms；S2 采样取指数外推稳态值而非瞬时值 |
| D4：参考腔 Vr 自身也可能被前驱体污染而漂移 | 中 | Vr 支路常压 Ar 正压保持，V3 仅在校准窗口开启且校准全程无前驱体进入；Vr 每 12 个月送计量室复检 |
| D5：Langmuir 单层模型对多层物理吸附前驱体（如高压 TEOS）失配 | 中 | 备选 BET 三参数模型；对超出模型适用域的工况回退至"Ar 基准脉冲比对"经验补偿 |
| D6：阻塞流泄放时工艺腔背压波动影响 S3 泄放量 | 低 | 剂量由 P₁−P₂ 压降定义，本质上与背压无关；仅需保证 P₂ 采样在 S4 回稳后 |
