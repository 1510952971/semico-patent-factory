## 一、技术领域

本发明涉及半导体制造用超高纯特种气体与液体前驱体供给技术领域，具体涉及一种用于原子层沉积（ALD）、原子层刻蚀（ALE）等自限制表面反应工艺的定容剂量式脉冲供气模块，以及基于该模块的单脉冲剂量闭环控制方法。

---

## 二、背景技术

### 2.1 现有技术一：热式质量流量控制器（Thermal MFC）

热式 MFC 通过毛细分流管上下游测温元件的温差感知质量流量，是半导体气体供给的主流计量器件。其固有缺陷在于传感器的热时间常数：典型毛细管—加热丝—测温元件系统的时间常数 τ 为 0.6~1.5 s，整机 0~100 % 满量程阶跃的稳定时间不低于 500 ms。

在 ALD/ALE 工艺中，前驱体以 5~500 ms 的脉冲形式供给。当脉冲宽度小于 MFC 稳定时间时，MFC 全程处于未建立的暂态，其示值既不反映瞬时流量、也不能对脉冲总量积分得到正确剂量，因而**测量功能与控制功能同时失效**。

### 2.2 现有技术二：压力式流量控制器（Pressure-Based Flow Controller）

压力式流量控制器在管路中设置临界流文氏管（音速喷嘴），当上下游压比大于约 2 时，通过喷嘴的质量流量仅由上游压力与温度决定，从而将流量测量转化为压力测量，响应时间可压缩至约 100 ms。

该方案仍存在两项限制：
- 响应时间仍不足以覆盖 10 ms 量级的脉冲；
- 必须维持上下游压比 > 2 的临界流条件。对低蒸汽压液体前驱体（例如六氯乙硅烷 HCDS 在 25 °C 下饱和蒸汽压仅约 4 Torr），上游可用压力极低，临界流条件无法建立，方案不适用。

### 2.3 现有技术三：定容剂量法（Dose Volume / Fill-and-Push）

为规避流量测量的速度瓶颈，业界转而采用"以容积定剂量"的思路：设置一个几何容积为 V₀ 的剂量腔，上游阀开启将腔体充填至压力 P₁ 后关闭，随后开启下游阀将腔内气体泄放至工艺腔，以理想气体状态方程计算标称剂量：

```
n = P₁ · V₀ / (R · T)
```

该方案取消了流量传感器，响应时间仅受阀动作速度限制，是当前 ALD 脉冲供气的主流手段。

**但该方案本质上是开环的**，其准确性完全依赖于"V₀ 为已知且不变的常量"这一前提。而在真实的前驱体工况下，该前提不成立，具体表现为两个相互独立的误差源：

**（1）有效容积的不可逆漂移**

三甲基铝（TMA）、四（二甲氨基）钛（TDMAT）、六氯乙硅烷（HCDS）、四（二甲氨基）铪等前驱体对电解抛光 316L 内壁存在化学吸附与表面寡聚反应，长期运行后在腔壁形成纳米至数十纳米量级的沉积层。以 V₀ = 5 cm³、内表面积约 22 cm²、电解抛光面实际比表面放大因子约 1.4 计，30 nm 厚沉积层即侵占约 9.2×10⁻⁵ cm³ 的容积。实测表明，以 HCDS 连续运行 10,000 个循环后，剂量腔有效容积由 5.0021 cm³ 降至 4.9128 cm³，**漂移达 1.79 %**。

该漂移是单向累积的，且现有技术只能通过**拆机、送计量室、以气体膨胀法离线重新标定容积**来修正。单次拆机停机 6~8 小时，且拆装过程破坏洁净度，重新装机后还需消耗 2~3 片监控晶圆重新验证工艺，代价极高。

**（2）可逆吸附/脱附造成的剂量系统偏差**

即使有效容积已知，前驱体分子在腔壁的可逆吸附也会使"压降换算剂量"系统性偏高：充填阶段被腔壁吸附的分子计入了压力建立过程，但在泄放阶段并未随气流带出。实测 TMA 在 150 °C、充填压力 18 Torr 条件下，该吸附偏差 n_ads 为 1.42×10⁻⁸ mol，占标称剂量 8.7×10⁻⁷ mol 的 **1.63 %**，且随腔壁老化而变化。

**（3）冷凝造成的隐性剂量丢失**

低蒸汽压前驱体在模块的局部冷点处冷凝为液相，既不计入压降计算，又会在后续脉冲的低压阶段不可控闪蒸，形成剂量尖峰与颗粒源。现有模块普遍仅对腔体本体做单点伴热，而阀体—腔体—管路的结合部因存在紧固件与接头形成的热桥空洞，实测温差可达 8~15 °C，是冷凝的高发部位。

### 2.4 现有技术的共性缺陷总结

综上，现有定容剂量法的根本缺陷是：**将"有效容积"和"吸附偏差"当作出厂时确定的常量，而它们实际上是随运行历史持续变化的变量；且现有技术不具备在不拆机、不停产条件下测量这两个量的手段**。这使得脉冲供气的剂量准确性只能靠频繁的离线标定与保守的过量投料（业界典型过量系数达 1.8 倍饱和剂量）来兜底，既损害工艺一致性，又造成昂贵前驱体的大量浪费。

**本发明即针对上述缺陷提出解决方案。**

## 三、发明内容

### 3.1 本发明要解决的技术问题

1. 如何在**不拆机、不停产**的条件下，在线测量定容剂量腔的**有效容积 V_eff**，从而补偿其因腔壁沉积而产生的不可逆漂移？
2. 在线测量过程本身如何避免被前驱体污染——即校准气体在腔壁上的吸附、以及前驱体在校准期间的窜入，都会使校准结果失真，如何从结构与时序上根除？
3. 如何将前驱体在腔壁的**可逆吸附偏差 n_ads** 从压降测量结果中在线分离出来，使其可被扣除？
4. 如何在结构上根除模块内的冷点与死区，消除冷凝造成的隐性剂量丢失与颗粒源，同时保证阀座的现场可维护性？

### 3.2 技术方案

#### 3.2.1 结构方案

本发明提供一种定容剂量式脉冲供气模块 (100)，包括：

**（a）定容剂量腔 (110)**：由 316L VIM-VAR 不锈钢一体化锻造成型的腔体，标称几何容积 V₀ = 5.000 cm³；其内表面经电解抛光至 Ra ≤ 0.13 μm，并形成厚度 ≥ 8 nm 的富铬钝化层，钝化层表面 Cr/Fe 原子比 ≥ 1.5。腔体内部沿入口射流轴线同轴设置**导流锥 (111)**，半锥角 22.5°，使入口射流沿腔壁形成附壁螺旋流，将腔内 95 % 体积的气体置换时间缩短至 8 ms 以内，并将角落回流死区体积压制在 0.8 % V₀ 以下。

**（b）恒温夹套 (112) 与腔壁温度传感器 (113)**：夹套由薄膜加热器与铝合金均温套构成，控温范围 40~200 °C，PID 控制精度 ±0.1 °C，腔壁六点温度均匀性 ±0.5 °C。两只 A 级 Pt100 (113) 经对角盲孔插入腔壁并以导热硅脂耦合。

**（c）上游高速阀 (120) 与下游高速阀 (130)**：均为压电叠堆直动式金属隔膜阀。隔膜材质为 Hastelloy C-22，表面复合 1.5 μm 无电解镀 Ni-P 与 Cr₂O₃ 钝化层。压电叠堆采用居里点 Tc > 320 °C 的 PZT 材料，叠堆与阀体之间设置长度 ≥ 12 mm 的**陶瓷隔热柱**，使叠堆在腔体 200 °C 工况下的实际工作温度不超过 90 °C。叠堆内置应变片构成行程闭环，**以阀座接触应力为被控量**，补偿高温下叠堆推力衰减。开启时间 ≤ 3 ms，关闭时间 ≤ 2 ms。

**（d）镶嵌式阀座座圈 (121)、(131)**：上、下游阀的阀座并非直接加工于腔体锻件之上，而是以 M14×0.75 螺纹压入腔体本体的**可拆卸镶嵌件**，座圈与腔体本体之间以 30° 金属对金属锥面密封。座圈座面材质按工作温度选取：≤ 150 °C 用 PCTFE，> 150 °C 用 Vespel SP-1。

> **该设计的意义**：阀座座圈直接嵌入腔体本体，取消了阀与腔体之间的两组 VCR 接头及其密封垫圈，将连接死区由 7.2 % V₀ 降至 0.61 % V₀，潜在漏点由 6 处减至 2 处，并消除了接头处的热桥空洞；同时因座圈可拆卸，阀座磨损后可现场单独更换，避免了"一体化即不可维护"的工程困境。

**（e）压力测量单元 (140)、(141)**：两只恒温至 150 °C 的电容薄膜压力计，满量程分别为 100 Torr（分辨率 0.001 Torr）与 1000 Torr（分辨率 0.01 Torr），双量程拼接覆盖全工作压力范围并互为交叉校验。

**（f）参考容积腔 (150) 与参考腔隔离阀 (151)**：**这是本发明的核心结构特征。** 参考容积腔 (150) 为 316L 制成的定容腔体，与剂量腔 (110) 一同置于恒温夹套内，经参考腔隔离阀 V3 (151) 与剂量腔 (110) 连通。参考腔的名义容积 **Vr\*** 定义为参考腔本体容积 Vr 与"参考腔至剂量腔之间的连接管路及 V3 阀腔的寄生容积 V_p"之和，在出厂时以 NIST 可溯源的方式一体标定，实测 Vr* = 1.1372 cm³ ± 0.05 %（其中 V_p = 0.1368 cm³）。

> **将 V_p 并入 Vr\* 一体标定，而非分别标定后相加**，是本发明在工程上的一个关键取舍：寄生容积的几何形状复杂（含阀腔、螺纹间隙、密封面倒角），单独测量不确定度大；而"参考腔连同其至剂量腔的全部通道"作为一个整体，其边界由 V3 阀座与剂量腔入口明确定义，可用膨胀法一次性溯源，不确定度仅 0.05 %。

**（g）校准/吹扫气阀 (160)**：V4 引入两路气体——氮气用于常规吹扫，**氩气用于容积自校准与基准剂量比对**。V4 至参考腔 (150) 设有专用微管路，使校准气可在不经过剂量腔的前提下单独充填参考腔。

**（h）控制器 (170)**：FPGA 结合 24 bit ΔΣ ADC，采样率 10 kHz，阀时序抖动 ≤ 20 μs。控制器执行 3.2.2~3.2.4 所述的全部时序与算法。

**（i）伴热拓扑**：自前驱体源 (180) 至工艺腔 (190) 的全通路实施**单调升温梯度**——管路伴热温升 ≥ 2 °C/m，上游阀体温度 ≥ 源温 +10 °C，剂量腔 ≥ 源温 +15 °C，下游阀体 ≥ 源温 +18 °C，至工艺腔法兰 ≥ 源温 +20 °C。判据为：通路上任意一点的温度不低于其上游全部点的最高温度。

#### 3.2.2 在线容积自校准方法（IVSC）

控制器在工艺间隙（典型为晶圆交换窗口）自动执行如下时序，全程耗时 ≤ 2.0 s：

| 步骤 | 阀状态 | 动作与采集 |
|---|---|---|
| **C1 抽空** | V1 关，V2 开，V3 开，V4 关 | 剂量腔与参考腔经下游阀抽空至 P₀₀ ≤ 0.01 Torr；同时对压力计执行零点重置 |
| **C2 隔离** | 全部阀关闭 | 建立初始隔离状态 |
| **C3 充参考腔** | V4 开（经专用微管路仅通参考腔），V1/V2/V3 保持关闭 | 以氩气将参考腔充填至 P_r0（典型 80 Torr），恒温平衡后记录 P_r0、T_r |
| **C4 膨胀** | V3 开，V1/V2/V4 关闭 | 氩气由参考腔向剂量腔自由膨胀，等待压力与温度平衡 |
| **C5 读数** | 全部阀关闭 | 记录平衡压力 P_f 与温度 T_f |

由物质量守恒解得剂量腔有效容积：

```
              Vr* · ( P_r0/T_r  −  P_f/T_f )
   V_eff  =  ────────────────────────────────
                  ( P_f  −  P₀₀ ) / T_f
```

**本方法有两项不可省略的限定条件，二者共同构成本发明相对于"把气体膨胀法直接搬用到剂量腔"的实质性区别：**

> **限定条件 α（校准介质的非吸附性）**：校准气体必须是在校准温度下于腔壁及腔壁沉积层上的表面覆盖度可忽略（≤ 10⁻³ 单层）的惰性气体。本发明选用**氩气**而非常规的氮气。
>
> **实证依据**：在经 HCDS 运行 5000 循环的腔体上，同一时刻分别以氩气与氮气执行本方法，并与拆机后计量室基准值 4.9531 cm³ 比对：
>
> | 校准介质 | 测得 V_eff (cm³) | 相对基准偏差 |
> |---|---|---|
> | **氩气** | 4.9524 | **−0.014 %** |
> | 氮气 | 4.9459 | −0.145 % |
>
> 氮气在含硅氧残留的腔壁上存在弱化学吸附，使平衡压力 P_f 偏低，从而系统性低估 V_eff 约 0.13 %——该量级已与本方法的目标不确定度（0.15 %）相当，若不加以限定则方法本身失去意义。

> **限定条件 β（校准期间的前驱体气路隔离）**：在 C1~C5 全部步骤中，连接前驱体源 (180) 的上游阀 V1 (120) 始终保持关闭，使前驱体气路与校准回路在物理上完全隔离；且校准气经专用微管路单独充填参考腔，不经由前驱体通路。
>
> **理由**：若校准期间有前驱体残余蒸汽窜入，其在膨胀过程中的吸附/脱附将直接叠加到压力平衡结果上，使 V_eff 解算失真；且前驱体一旦进入参考腔，将污染作为传递标准的 Vr*，造成不可恢复的标定失效。

#### 3.2.3 吸附偏差在线分离方法（ABS）

为分离可逆吸附偏差 n_ads，控制器执行**双温调制标定**：

1. 在夹套温度 T_a（例如 150 °C）下，以充填压力序列 P₁ ∈ {5, 10, 18, 25, 40} Torr 分别充填剂量腔，平衡后记录气相压力；
2. 将夹套温度切换至 T_b（例如 165 °C），对同一充填物质量重复上述测量；
3. 由两温度下气相物质量相对理想值的偏离，按 Langmuir 等温式拟合：

```
   θ(P,T) = K(T)·P / ( 1 + K(T)·P ) ,   K(T) = K₀ · exp( −ΔH_ads / (R·T) )
   n_ads(P,T) = n_m · θ(P,T)
```

实测 TMA 体系的拟合结果为：饱和吸附量 n_m = 3.14×10⁻⁸ mol，吸附焓 ΔH_ads = −41.7 kJ/mol，K₀ = 2.06×10⁻⁵ Torr⁻¹，拟合优度 R² = 0.987。

该标定在每 2000 个工艺循环后或每次更换前驱体源后执行一次，耗时 ≤ 60 s。控制器据此在任意工况下实时计算并扣除 n_ads。

#### 3.2.4 逐脉冲剂量闭环控制方法（PPDM）

对第 k 个工艺脉冲执行四阶段时序：

| 阶段 | 阀状态 | 时长 | 动作 |
|---|---|---|---|
| S1 充填 | V1 开，V2 关 | t_fill(k)，3~50 ms | 由源侧充填剂量腔 |
| S2 平衡 | 全关 | 5~20 ms | 采样压力序列并**指数外推至稳态**，得 P₁、T₁ |
| S3 泄放 | V1 关，V2 开 | t_dose，5~500 ms | 向工艺腔泄放 |
| S4 回稳 | 全关 | 5~20 ms | 采样得 P₂、T₂ |

实际交付剂量：

```
   n_k = (V_eff / R) · [ P₁/(Z₁·T₁) − P₂/(Z₂·T₂) ] − n_ads(P₁,P₂,T)
```

其中 V_eff 取自最近一次 IVSC 结果，n_ads 取自最近一次 ABS 标定的模型，Z 为压缩因子（低压时取 1，高压有机源按 Peng-Robinson 方程修正）。

控制器以增量式 PI 律修正下一脉冲的充填时长：

```
   e_k = n_set − n_k
   t_fill(k+1) = t_fill(k) + Kp·( e_k − e_{k−1} ) + Ki·e_k
```

整定值 Kp = 0.42，Ki = 0.18。阶跃剂量指令下，3 个脉冲内进入 ±0.5 % 带内且无超调。

> **注**：S2 阶段采用"指数外推稳态值"而非直接读取瞬时压力，是为消除绝热充填后气体温度高于壁温所致的读数偏差。经导流锥 (111) 强化壁面对流后，实测热弛豫时间常数 ≤ 4 ms，外推可在 5 ms 内收敛。

#### 3.2.5 自适应校准触发策略

IVSC 的执行间隔 N_cal 为自适应值：正常运行取 500 个循环；当连续两次 IVSC 结果的相对变化超过 0.2 % 时收紧至 200；当连续五次变化均小于 0.05 % 时放宽至 1000。实测长程运行中平均 N_cal = 780，IVSC 累计占用晶圆交换窗口的时间比例低于 0.4 %，不影响产能。

### 3.3 有益效果（量化数据支撑）

#### 效果一：剂量长程漂移抑制 4.8 倍

以 HCDS 为介质、连续运行 10,000 个循环（等效 30 天）的对照试验：

| 配置 | 10⁴ 循环剂量漂移 |
|---|---|
| IVSC 关 + ABS 关（等效现有技术的开环定容法） | **2.24 %** |
| IVSC 开 + ABS 关 | 0.89 % |
| **IVSC 开 + ABS 开（本发明）** | **0.37 %** |

### 权利要求 8（独立权利要求 · 方法）

**8.** 一种定容剂量式脉冲供气的剂量闭环控制方法，应用于权利要求 1 至 7 中任一项所述的模块 (100)，其特征在于，包括：

- **(S1)** 开启上游高速阀 (120) 并保持充填时长 t_fill(k)，将前驱体充填入定容剂量腔 (110)，随后关闭；
- **(S2)** 在全部阀关闭状态下等待热平衡，以不低于 1 kHz 的速率采集压力序列并将其指数外推至稳态，得到充填后压力 P₁ 与温度 T₁；
- **(S3)** 开启下游高速阀 (130) 并保持泄放时长 t_dose，向工艺腔 (190) 泄放，随后关闭；
- **(S4)** 在全部阀关闭状态下等待回稳，得到泄放后压力 P₂ 与温度 T₂；
- **(S5)** 按下式计算第 k 个脉冲的实际剂量：

```
n_k = ( V_eff / R ) · [ P₁/(Z₁·T₁) − P₂/(Z₂·T₂) ] − n_ads(P₁,P₂,T)
```

其中 V_eff 为由权利要求 1 所述在线容积自校准最近一次测得的有效容积，Z 为压缩因子，n_ads 为前驱体在所述定容剂量腔内表面的可逆吸附偏差；
- **(S6)** 以 e_k = n_set − n_k 为偏差，按增量式比例—积分律 t_fill(k+1) = t_fill(k) + Kp·(e_k − e_{k−1}) + Ki·e_k 修正下一脉冲的充填时长；
- **(S7)** 每间隔 N_cal 个脉冲，于工艺间隙执行一次所述在线容积自校准以更新 V_eff。

### 权利要求 9

**9.** 根据权利要求 8 所述的方法，其特征在于，所述可逆吸附偏差 n_ads 由双温调制标定在线确定，所述双温调制标定包括：使所述定容剂量腔 (110) 的腔壁温度在第一温度 T_a 与第二温度 T_b 之间切换，T_b − T_a 不小于 10 °C；在两个温度下分别以同一组充填压力序列充填并测得平衡后的气相压力；由两温度下气相物质量相对理想气体状态方程计算值的偏离，拟合吸附等温式 n_ads(P,T) = n_m · K(T)·P / (1 + K(T)·P)，其中 K(T) = K₀·exp(−ΔH_ads/(R·T))，解出饱和吸附量 n_m、吸附焓 ΔH_ads 与前置因子 K₀，进而在任意工况下实时计算并在步骤 (S5) 中扣除 n_ads。

### 权利要求 10

**10.** 根据权利要求 8 所述的方法，其特征在于，所述间隔 N_cal 为自适应值，其调节规则为：当最近两次在线容积自校准所得有效容积的相对变化大于第一阈值时，将 N_cal 减小；当最近连续多次在线容积自校准所得有效容积的相对变化均小于第二阈值时，将 N_cal 增大；所述第一阈值大于所述第二阈值；且所述在线容积自校准仅在工艺腔 (190) 处于可提供抽空条件的晶圆交换窗口内触发。

### 权利要求 11

**11.** 根据权利要求 8 所述的方法，其特征在于，还包括将所述在线容积自校准所得有效容积 V_eff 的时间序列及其变化速率 dV_eff/dN 输出至设备故障检测与分类系统，作为所述定容剂量腔内壁沉积累积量的表征量；当 dV_eff/dN 超过预设阈值时输出腔体清洗预警。

## 六、具体实施方式

### 实施例 1：HCDS（六氯乙硅烷）供给用 5 cm³ 模块 —— 长程剂量稳定性验证

**配置**：定容剂量腔 (110) V₀ = 5.000 cm³，恒温夹套 (112) 设定 150 °C；参考容积腔 (150) Vr* = 1.1372 cm³；校准气体为氩气；前驱体源 (180) 为 HCDS 蒸汽抽取钢瓶，源温 45 °C，饱和蒸汽压约 4 Torr；工艺腔 (190) 背压 ≤ 3 Torr。

**伴热梯度实测**（按权利要求 7）：

| 位置 | 实测温度 (°C) |
|---|---|
| 源出口 | 45.1 |
| 管路中段（1.8 m 处） | 48.8（沿程 2.6 °C/m） |
| 上游阀 (120) 阀体 | 57.3 |
| 定容剂量腔 (110) | 62.1 |
| 下游阀 (130) 阀体 | 64.0 |
| 至工艺腔法兰 | 64.5 |

红外热像扫描全通路，任意点温度均不低于其上游各点最高温度，无冷点。

**运行条件**：t_fill = 12 ms，t_dose = 30 ms，脉冲周期 1.2 s，连续运行 30 天共 10,000 个工艺循环。每 500 循环插入一组氩气基准脉冲（5 个）作独立比对。N_cal 按权利要求 10 自适应，实测平均 780。

**结果**：

| 时间 | 基准剂量偏差（相对 Day-0） | IVSC 报告 V_eff (cm³) |
|---|---|---|
| Day 0 | 0.00 % | 5.0018 |
| Day 5 | −0.09 % | 4.9871 |
| Day 10 | −0.16 % | 4.9702 |
| Day 15 | −0.22 % | 4.9563 |
| Day 20 | −0.28 % | 4.9401 |
| Day 25 | −0.33 % | 4.9268 |
| Day 30 | **−0.37 %** | 4.9134 |

腔体有效容积在 30 天内单向漂移 1.77 %，而经本发明在线补偿后，实际交付剂量仅漂移 0.37 %，**误差抑制比 4.8 倍**。

**对照组**（同一台模块，关闭 IVSC 与 ABS，等效现有开环定容法）：同条件 10,000 循环后剂量漂移 **2.24 %**，超出工艺允许的 0.5 % 上限四倍以上。

**运行结束后拆检**：腔内壁及阀座区域无液态冷凝痕迹；下游 CNC 采样 ≥0.1 μm 颗粒 0.34 particle/L。

### 实施例 2：TMA（三甲基铝）供给用模块 —— 吸附偏差在线分离与 QCM 独立验证

**配置**：同实施例 1 硬件，夹套温度 160 °C；前驱体源为 TMA 鼓泡器，源温 25 °C。

**双温调制标定**（按权利要求 9）：T_a = 150 °C，T_b = 165 °C（ΔT = 15 °C ≥ 10 °C 限定），充填压力序列 P₁ ∈ {5, 10, 18, 25, 40} Torr。

拟合结果：

| 参数 | 值 | 95 % 置信区间 |
|---|---|---|
| 饱和吸附量 n_m | 3.14×10⁻⁸ mol | ±4.1 % |
| 吸附焓 ΔH_ads | −41.7 kJ/mol | ±2.8 kJ/mol |
| 前置因子 K₀ | 2.06×10⁻⁵ Torr⁻¹ | ±11 % |
| 拟合优度 R² | 0.987 | — |

在典型工况 P₁ = 18 Torr、150 °C 下，模型给出 n_ads = 1.42×10⁻⁸ mol，占标称剂量 8.7×10⁻⁷ mol 的 **1.63 %**。若不按权利要求 9 扣除该项，剂量将系统性偏高 1.63 %。

**QCM 独立比对**：在工艺腔内安装石英晶体微天平，TMA/H₂O ALD、160 °C，采集 120 个数据点，剂量范围 2×10⁻⁸ ~ 4×10⁻⁷ mol。

- 线性回归：m_QCM = 26.84 × n_DVPDM + 0.31（ng vs. 10⁻⁸ mol）
- **R² = 0.991**，残差标准差 0.42 ng（相对 1.4 %，其中 QCM 自身噪声约 1.1 %）
- 回归斜率理论值（按 QCM 有效面积 1.37 cm² 与 TMA 饱和覆盖度折算）为 26.1，实测 26.84，偏差 2.8 %，落在 QCM 有效面积不确定度范围内。

该结果确认：本发明所计算并报告的剂量 n_k 与工艺腔内的实际沉积量之间具有严格的物理线性对应关系，剂量值可直接用于工艺配方设定，而非仅作为相对指示。

### 实施例 3：氩气基准条件下的重复性与在线校准不确定度验证

**配置**：同实施例 1 硬件；介质全程使用氩气（消除吸附项以隔离评估模块本身的计量能力）；夹套 150 °C。

**（3-1）单脉冲剂量重复性**：P₁ = 20 Torr，t_dose = 20 ms，连续 1000 脉冲。

| 统计量 | 值 |
|---|---|
| 剂量均值 | 8.712×10⁻⁷ mol |
| 标准差 1σ | 1.83×10⁻⁹ mol |
| **相对重复性 1σ** | **0.21 %** |
| 极差（max − min） | 1.14 % |
| Mann-Kendall 趋势检验 | p = 0.42（无显著趋势） |

**（3-2）在线容积自校准的实测时序与结果**（按权利要求 1 特征 (f)）：

| 步骤 | 阀状态 | 耗时 | 实测值 |
|---|---|---|---|
| C1 抽空 | V1 关，V2 开，V3 开 | 620 ms | P₀₀ = 0.004 Torr（同步完成压力计零点重置） |
| C2 隔离 | 全关 | 40 ms | — |
| C3 充参考腔 | V4 开（专用微管路） | 260 ms | P_r0 = 80.14 Torr，T_r = 150.02 °C |
| C4 膨胀 | V3 开 | 420 ms | — |
| C5 读数 | 全关 | 340 ms | P_f = 14.86 Torr，T_f = 150.05 °C |
| **合计** | | **1.68 s** | V_eff = 5.0018 cm³ |

不确定度分解（k = 2）：

| 分量 | 贡献 |
|---|---|
| Vr* 溯源 | 0.050 % |
| 压力计线性度与迟滞 | 0.052 % |
| 温度不均（±0.34 °C） | 0.041 % |
| 压力读数噪声（100 点均值） | 0.024 % |
| 零点残余 | 0.031 % |
| **合成 U(k=2)** | **0.13 %** |

**（3-3）校准气体选择的验证实验**（支撑权利要求 1 特征 (e) 与权利要求 2）：

在同一台经 HCDS 运行 5000 循环的"已污染"腔体上，同一时刻分别以氩气与氮气执行在线容积自校准，随后拆机送计量室以标准膨胀法测得基准值 4.9531 cm³：

| 校准介质 | 测得 V_eff (cm³) | 相对基准偏差 |
|---|---|---|
| **氩气** | 4.9524 | **−0.014 %** |
| 氮气 | 4.9459 | −0.145 % |

氮气因在含硅氧残留的腔壁上存在弱化学吸附，使膨胀平衡压力 P_f 偏低，系统性低估有效容积约 0.13 %——该偏差量级已与本方法的目标不确定度相当。这一实验直接证明：权利要求 1 特征 (e) 关于"校准气体须为表面覆盖度可忽略的惰性气体"的限定，并非可有可无的常规选择，而是本方法能否达到 0.15 % 不确定度目标的**决定性技术特征**。

**（3-4）前驱体气路隔离的验证**（支撑权利要求 1 特征 (f)）：故意在校准的 C4 膨胀步骤中将上游阀 (120) 短暂开启 5 ms，使 HCDS 蒸汽微量窜入。结果：该次校准解得 V_eff = 5.0742 cm³，相对正确值偏高 **1.45 %**，且该错误值一旦被写入控制器，将使后续全部脉冲剂量系统性偏高 1.45 %。此实验说明特征 (f) 中"上游高速阀在校准全程保持关闭"的限定是本方法成立的必要条件。

## 七、说明书摘要

本发明公开一种具有在线容积自校准功能的超高纯定容剂量式脉冲供气模块及其剂量闭环控制方法，属半导体特种气体供给技术领域。模块包括定容剂量腔、上下游压电高速隔膜阀、恒温夹套、电容薄膜压力计，以及经隔离阀与剂量腔连通的**参考容积腔**；参考容积腔的名义容积包含其本体容积与至剂量腔之连接通道的寄生容积并一体溯源标定。控制器在工艺间隙、于上游阀保持关闭使前驱体气路完全隔离的前提下，以在校准温度下表面覆盖度可忽略的惰性气体（氩气）经专用管路单独充填参考容积腔，随后使其向剂量腔自由膨胀，由膨胀前后压力与温度解算剂量腔有效容积，全程耗时 1.68 s，不确定度 0.13 %（k=2），无需拆机停产。控制器进一步以双温调制法在线分离前驱体在腔壁的可逆吸附偏差，并按逐脉冲压降计算实际剂量、以增量式 PI 律闭环修正充填时长。实测表明，在腔体有效容积因壁面沉积而漂移 1.77 % 的条件下，本发明将 10⁴ 循环的实际交付剂量漂移由现有开环定容法的 2.24 % 压制至 0.37 %，单脉冲剂量重复性 0.21 %（1σ），并经石英晶体微天平独立比对确认所报告剂量与实际沉积量线性相关（R² = 0.991）。
