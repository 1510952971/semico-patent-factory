## 一、项目背景与痛点

### 1.1 制程侧的水分容限已经压到 ppb 量级

在 3nm/N2 节点的 GAA 环栅制程与 232 层以上 3D NAND 的高深宽比（HAR, AR>60:1）刻蚀中，刻蚀与清洗环节大量使用 HCl、Cl₂、HBr、BCl₃、WF₆、NF₃ 等强腐蚀性特种气体。这些气体中的微量水分会造成三类直接良率损失：

| 气体 | 水分引发的失效机理 | 制程后果 |
|---|---|---|
| HCl / HBr | H₂O 使气体由"干态分子"转为"湿态酸"，对 316L/Hastelloy 管路产生点蚀，脱落 FeCl₂/NiCl₂ 颗粒 | 金属污染、颗粒 adder |
| Cl₂ | 与 Al 硬掩膜反应生成 AlCl₃·6H₂O，在腔壁与泵口结晶 | 侧壁粗糙度劣化、非计划停机 |
| WF₆ | WF₆ + H₂O → WOF₄ / WO₂F₂ 固体 + HF；HF 反侵蚀阀座与石英件 | W 塞空洞、接触电阻漂移 |
| BCl₃ | BCl₃ + 3H₂O → H₃BO₃ + 3HCl，生成硼酸固体粉末 | 喷淋头（showerhead）孔堵塞 |
| NF₃ | 水分导致等离子体解离路径改变，F 自由基产额波动 | 腔体清洗（chamber clean）终点漂移 |

主流 Fab 对上述气体的钢瓶出口 / 使用点（POU）水分规格已由 2015 年前后的 < 1 ppmv 收紧至 **< 20 ppbv（钢瓶出口）/ < 50 ppbv（POU）**，且要求**在线连续监测**而非离线取样（离线取样管路本身的吸附解吸会引入 100 ppb 量级的假信号）。

### 1.2 现有在线检测手段在腐蚀性基底气中集体失效

| 技术路线 | 在腐蚀性气体中的失效模式 |
|---|---|
| 电容式（Al₂O₃ / SiO₂）露点仪 | 敏感层被 HCl/HBr 化学侵蚀，3~8 周即中毒失效；且在酸性基底中零点单向漂移 |
| 石英晶体微天平（QCM） | 涂层吸湿层被腐蚀气取代，选择性丧失 |
| 电解式（P₂O₅） | 与 Cl₂/HBr 直接反应，寿命 < 2 周 |
| FTIR / TDLAS 直接吸收 | 光程内 ppb 级水分吸光度 ~10⁻⁶，低于直接吸收法基线噪声 2 个数量级 |
| **腔衰荡光谱（CRDS）** | **灵敏度足够（可达 10⁻¹¹ cm⁻¹），但腔镜（R > 99.998%）的高反膜在腐蚀气中数百小时即劣化** |

CRDS 是唯一在灵敏度维度上满足 ppb 需求的路线，因此**问题被收敛为：如何在腐蚀性基底气中保住腔镜**。

### 1.3 本项目要攻的真正痛点：护罩边界层的"不可标定稀释"

工业界对腔镜腐蚀的既有解法是**镜面惰性气体护罩（mirror purge）**——在两端腔镜前方经环形扩散器持续吹入干燥惰性气体，形成一层贴近镜面的保护流，把腐蚀性样气"顶"离镜面。该方法确实延长了镜片寿命，但引入了一个**在 ppb 计量中致命的系统误差**：

CRDS 测得的是**腔内平均吸收系数** ᾱ：

```
ᾱ = (1/L) ∫₀^L α(x) dx
```

护罩区（两端各长度 δ）内为干燥护罩气，水分浓度远低于样气。设护罩区吸收系数为 α_p、样气段为 α_s，则：

```
ᾱ · L = α_s · (L − 2δ) + α_p · 2δ
```

于是**真实样气浓度被系统性低估**，低估比例为 2δ/L。而 δ 并非常数：

1. **随护罩流量变化**：护罩流量 20 → 40 sccm，δ 由 6.1 mm 变到 11.2 mm（本项目前期 PIV/示踪实测）；
2. **随池压变化**：池压 300 → 600 Torr，δ 再变化 ±1.8 mm；
3. **随镜面与喷嘴长期污染单向漂移**：环形扩散器出口沉积改变出流均匀性，6000 h 后 δ 由 8.7 mm 漂移至 12.4 mm。

对 L = 420 mm 的单腔而言，2δ/L 对应的示值偏差为 −2.9% ~ −5.9%，且**长期漂移约 −1.8%/年、方向单调**。这一误差**无法通过标气标定消除**——因为标定时的 δ 与实际工况下的 δ 不同，且 δ 不可在线测量。这正是护罩式 CRDS 在腐蚀性气体在线计量中始终无法通过 Fab 计量确认（MSA）的根因。

> **本项目的技术命题**：在不牺牲镜面保护的前提下，使测量结果**在原理上与 δ 无关**。

## 二、技术目标与量化指标

### 2.1 总体目标

研制一套可直接安装于 GC（气柜）/ VMB（阀门分配箱）取样支路的在线微量水分检测模块，在 HCl、Cl₂、HBr、WF₆、NF₃、BCl₃ 基底气中实现 ppb 级连续监测，且护罩相关系统偏差在原理上被消除。

### 2.2 量化指标

| 序号 | 指标项 | 目标值 | 考核方法 |
|---|---|---|---|
| T-1 | 检出限 LOD（3σ，60 s 平均，差分模式） | ≤ 5.0 ppbv | 干燥 N₂ 下行至平衡后连续采集 2 h，取 3× 标准差 |
| T-2 | 检出限 LOD（3σ，10 s 平均，快速模式） | ≤ 12 ppbv | 同上 |
| T-3 | 量程 | 5 ppbv ~ 20 ppmv | 渗透管动态配气 |
| T-4 | **护罩相关系统偏差** | **≤ 0.5%（相对示值）** | 护罩流量 20/30/40 sccm × 池压 300/500/600 Torr 全组合下示值极差 |
| T-5 | **护罩偏差长期漂移** | **≤ 0.3%/年** | 6000 h 加速老化前后同一标气示值之差外推 |
| T-6 | 合成扩展不确定度 U（k=2，不含标气溯源） | ≤ 1.5% | GUM 不确定度预算 + 比对验证 |
| T-7 | t₉₀ 响应时间（1 ppmv → 10 ppbv 下行） | ≤ 150 s | 阶跃切换 + 时间常数拟合 |
| T-8 | 腔镜寿命（HCl 6N，60 °C 连续） | ≥ 6000 h 且 LOD 劣化 ≤ 30% | 加速老化台架 |
| T-9 | 采样池外漏率 | < 1×10⁻¹⁰ atm·cc/s He | 氦质谱检漏 |
| T-10 | 采样池内表面 | Hastelloy C-22 电解抛光 Ra ≤ 0.13 μm | 白光干涉 + SEM |
| T-11 | 样气消耗 | ≤ 250 sccm（含护罩自源分流） | 流量计量 |
| T-12 | 护罩边界层厚度 δ 在线反演能力 | 可输出 δ 估计值，分辨率 ≤ 0.3 mm | 与示踪法比对 |

> 指标 T-4 / T-5 是本项目的**创新性指标**——现有护罩式 CRDS 在该两项上分别为 ~3.1%（k=2）与 ~1.8%/年。

## 三、研发路线图与路线选择

### 3.1 路线比选

| 候选路线 | 原理 | 否决/采纳理由 |
|---|---|---|
| R1 无护罩 + 耐蚀镜膜 | 采用 Y₂O₃ / AlF₃ 保护层高反膜直接暴露 | **否决**：保护层引入附加损耗，1−R 由 1.5×10⁻⁵ 劣化至 8×10⁻⁵，τ₀ 下降 5.3 倍，LOD 无法达标；且 HBr 工况下 200 h 仍出现雾化 |
| R2 护罩 + 固定校正因子 | 出厂标定一个 2δ/L 常数 | **否决**：δ 随流量/压力/老化变化，正是痛点本身 |
| R3 护罩 + 在线示踪测 δ | 注入示踪气反演 δ | **否决**：示踪气污染样气；且示踪气与水分的扩散系数不同，δ 不等价 |
| R4 双腔差分（一腔充参考气） | 参考腔充干燥气做基线扣除 | **否决**：参考腔无样气，护罩区贡献不可比，δ 无法消除；且属已知技术（差分吸收） |
| **R5 双不等基长腔差分（本项目）** | **两腔基长不等、护罩几何与流量严格相同，联立消 δ** | **采纳**：δ 与 α_p 在数学上被同时消去，且不引入任何附加气种 |

### 3.2 核心原理（R5）

设两只**内径相同、护罩喷嘴几何相同、护罩流量相同、样气并联同源**的衰荡腔，腔长分别为 L₁、L₂（L₁ > L₂），则两腔的护罩边界层厚度 δ 与护罩区吸收系数 α_p 相同：

```
ᾱ₁ · L₁ = α_s · (L₁ − 2δ) + α_p · 2δ        …… (1)
ᾱ₂ · L₂ = α_s · (L₂ − 2δ) + α_p · 2δ        …… (2)
```

(1) − (2)：**含 δ 项与含 α_p 项同时抵消**：

```
ᾱ₁L₁ − ᾱ₂L₂ = α_s (L₁ − L₂)

           ᾱ₁L₁ − ᾱ₂L₂
→   α_s = ───────────────                    …… (3)  【核心解算式】
             L₁ − L₂
```

**式 (3) 的两项工程意义**：

- **δ 被消除**：护罩流量、池压、镜面老化引起的 δ 变化不再影响测量结果；
- **α_p 被消除**：护罩气自身的残余水分**不需要低到可忽略**，也不需要被测量——这直接放宽了护罩气纯化器的规格要求，并使"自源护罩"成为可能。

同时可反演护罩边界层厚度作为诊断量：

```
        L₁L₂ (ᾱ₁ − ᾱ₂)
2δ = ──────────────────── ／ (α_s − α_p)  的等价形式，工程上取
        
        L₁ (α_s − ᾱ₁)
2δ = ─────────────────                       …… (4)  【δ 在线反演式】
          α_s − α_p
```

式 (4) 输出的 δ 时间序列即为**镜面/护罩喷嘴健康度**的内生诊断量（对应指标 T-12）。

### 3.3 自源护罩（Self-Sourced Purge）设计

传统护罩用高纯 N₂。但 N₂ 与 HCl/Cl₂ 的**压力展宽系数不同**（γ_N₂ ≈ 0.090 vs γ_HCl ≈ 0.112 cm⁻¹/atm @ 7181 cm⁻¹ 水分线），导致样气段与护罩段的吸收线型不一致，式 (1)(2) 的线型一致性前提被破坏，残余误差约 0.8%。

本项目采用**自源护罩**：从样气主路分流一股，经耐酸型深度脱水纯化器（分子筛 3A + 耐酸粘结剂，出口 H₂O < 0.5 ppbv）后回注为护罩气。由于式 (3) 已消去 α_p，护罩气"没有脱到 0"完全不影响结果；而基底气种完全相同，线型一致性严格成立，且不额外消耗 N₂、不稀释样气基底。

### 3.4 结构参数选型论证

**基长比 L₁/L₂ 的两难**：

由式 (3) 作误差传递，噪声放大因子为：

```
G = √[ (L₁/(L₁−L₂))² + (L₂/(L₁−L₂))² ]
```

| L₁/L₂ | G（噪声放大） | 2δ/L₂ @ δ=8.7mm（差分有效性） | 评价 |
|---|---|---|---|
| 1.5 | 3.61 | 依 L₂ 而定 | 噪声放大过大 |
| 2.0 | 2.24 | 8.3%（L₂=210mm） | 折中偏差 |
| **3.0** | **1.58** | **12.4%（L₂=140mm）** | **选定** |
| 6.0 | 1.22 | 24.9%（L₂=70mm） | τ₀₂ 仅 15.6 μs，数字化与拟合精度不足；短腔机械稳定性差 |

选定 **L₁ = 420.00 mm、L₂ = 140.00 mm（比值 3.0）**，理由：

- G = 1.58 的噪声代价可接受（LOD 由单腔 2.2 ppb 变为 3.5 ppb，仍满足 T-1 ≤ 5 ppb）；
- 长短腔的稀释率分别为 4.14% 与 12.43%，**相差 8.3 个百分点**，差分信号充分（若两腔稀释率接近，式 (3) 分子趋近于零，条件数恶化）；
- τ₀₂ = 31.1 μs，满足 100 MS/s 采集下的指数拟合精度要求。

### 3.5 攻关难点

| 难点 | 描述 | 应对措施 |
|---|---|---|
| **D-1 两腔 δ 的严格相等** | 式 (3) 成立的唯一前提；δ₁ ≠ δ₂ 时残余误差 = −2Δδ/(L₁−L₂) | 同批次镜片、同模具环形烧结扩散器、同规格 MFC 并做流量互校、两腔内径同为 12.0 mm |
| **D-2 样气两腔同源同态** | 串联会因上游腔壁吸附改变下游浓度 | 等长等阻并联歧管，两支路流导差 < 1.5%，管长差 < 2 mm |
| **D-3 腐蚀环境下的低吸附内表面** | 水分在壁面吸附解吸造成 t₉₀ 拖尾与零点漂移 | Hastelloy C-22 电解抛光 Ra ≤ 0.13 μm + 全程恒温 60.0 °C |
| **D-4 标准具条纹（etalon fringe）** | 两腔条纹不相关，被 G=1.58 放大 | 腔镜楔角 0.5°、腔体轴向 PZT 抖动平均、窗口件斜置 |
| **D-5 高浓度下的过渡区非阶跃** | > 5 ppmv 时护罩/样气界面浓度梯度显著，"阶跃廓形"假设失效 | 限定高精度量程 ≤ 5 ppmv，5~20 ppmv 段给出非线性修正曲线 |
| **D-6 水解固体产物沉积** | BCl₃/WF₆ 遇水生成 H₃BO₃ / WO₂F₂ 固体，沉积于歧管改变流导对称性 | 60 °C 恒温 + 定期 N₂ 反吹 + 歧管流导在线互校 |

## 七、与已有项目的区分（防重复声明）

已完成项目 PROJ-001 为《具有在线容积自校准功能的超高纯定容剂量式脉冲供气模块》，其技术内核为**压力—容积法的剂量计量与闭环控制**，服务对象为 ALD/ALE 前驱体供给。

本项目 PROJ-002 在以下维度与之无重合：

| 维度 | PROJ-001 | PROJ-002 |
|---|---|---|
| 被测物理量 | 前驱体剂量（mol） | 气体中水分浓度（ppbv） |
| 计量原理 | 压力—容积—温度（PVT）法 | 腔衰荡光谱吸收法 |
| 核心不确定量 | 剂量腔有效容积 V_eff（沉积漂移） | 护罩边界层厚度 δ（流场/污染漂移） |
| 消除手段 | 内置参考容积腔 + 气体膨胀自校准 | 双不等基长腔差分联立 |
| 装置位置 | 工艺腔上游供气支路（in-line） | GC/VMB 取样支路（side-stream） |
| 主要材料挑战 | 前驱体壁面沉积 | 强酸腐蚀与高反膜劣化 |

二者仅在"气体设备的自诊断能力"这一宏观理念上同属一个技术家族，具体结构、原理与权利要求保护客体完全不同。
