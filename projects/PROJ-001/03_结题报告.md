## 二、关键技术突破

### 2.1 突破一：在线容积自校准（IVSC）——把"开环定容"变成"可溯源定容"

**问题回顾**：前驱体在剂量腔内壁形成吸附/寡聚沉积层，使有效容积 V_eff 单向漂移。项目前期在对照样机上做了漂移的直接测量：以 HCDS 连续运行 10,000 循环（等效 30 天），拆机用计量室膨胀法复测，V_eff 由初始 5.0021 cm³ 降至 4.9128 cm³，**漂移 1.79 %**，与计划书预估的 0.8 %~2.5 % 区间吻合。这一数据首次在本项目内部量化确认了痛点的真实幅度。

**实现方案**（最终定型，含 R-02 修正）：

三容积模型（V₀ 剂量腔、Vr 参考腔、V_p 寄生容积；Vr* ≡ Vr + V_p 出厂合并溯源）：

```
        Vr* · (P_r0/T_r − P_f/T_f)
V_eff = ───────────────────────────
             (P_f − P₀₀)/T_f
```

时序（实测 1.68 s，嵌入晶圆交换窗口）：

| 步骤 | 阀状态 | 实测耗时 | 实测值 |
|---|---|---|---|
| C1 抽空 | V2 开、V3 开 | 620 ms | P₀₀ = 0.004 Torr |
| C2 隔离 | 全关 | 40 ms | — |
| C3 充参考腔 | V4 开（微管路仅通 Vr） | 260 ms | P_r0 = 80.14 Torr，T_r = 150.02 °C |
| C4 膨胀 | V3 开 | 420 ms | — |
| C5 读数 | 全关 | 340 ms | P_f = 14.86 Torr，T_f = 150.05 °C |

**校准介质选择的实证**：项目做了 Ar 与 N₂ 的对照实验。在经 HCDS 运行 5000 循环的"脏"腔体上，同一时刻分别用 Ar 与 N₂ 执行 IVSC：

| 介质 | 测得 V_eff (cm³) | 与拆机计量室基准 4.9531 cm³ 之偏差 |
|---|---|---|
| Ar | 4.9524 | **−0.014 %** |
| N₂ | 4.9459 | **−0.145 %** |

N₂ 在含硅氧残留表面存在弱吸附，系统性低估 V_eff 约 0.13 %。该实验直接支撑了权利要求 1 中"非吸附惰性校准气体"特征的技术效果论证。

**不确定度实测分解（k=2）**：

| 分量 | 贡献 |
|---|---|
| Vr* 溯源 | 0.050 % |
| CDG-L 线性度与迟滞 | 0.052 % |
| 温度不均（±0.34 °C） | 0.041 % |
| 压力读数噪声（100 点均值） | 0.024 % |
| 零点残余（C1 顺带重置后） | 0.031 % |
| **合成 U(k=2)** | **0.13 %** |

### 2.2 突破二：吸附偏差在线分离（ABS）——双温调制

**验证工艺**：TMA（三甲基铝）@ 150/165 °C，充填压力 5~40 Torr。

在两个夹套温度下测同一充填量的平衡压力，由气相物质量偏离理想值的差额解出 Langmuir 参数：

| 参数 | 拟合值 | 95 % 置信区间 |
|---|---|---|
| 饱和吸附量 n_m | 3.14×10⁻⁸ mol | ±4.1 % |
| 吸附焓 ΔH_ads | −41.7 kJ/mol | ±2.8 kJ/mol |
| K₀ | 2.06×10⁻⁵ Torr⁻¹ | ±11 % |

拟合优度 R² = 0.987。在典型工况（P₁ = 18 Torr，150 °C）下，n_ads = 1.42×10⁻⁸ mol，占标称剂量 8.7×10⁻⁷ mol 的 **1.63 %**——若不扣除，即为 1.63 % 的系统性剂量偏高。

**ABS 开/关的对照效果**（HCDS，10⁴ 循环长程试验）：

| 配置 | 剂量漂移（10⁴ 循环） |
|---|---|
| IVSC 关 + ABS 关（模拟现有技术开环定容） | 2.24 % |
| IVSC 开 + ABS 关 | 0.89 % |
| **IVSC 开 + ABS 开（本项目方案）** | **0.37 %** |

结论清晰：容积漂移与吸附偏差是两个独立的误差源，**必须同时治理**，只做其一无法达标。这一对照数据是本项目专利"有益效果"章节的核心证据。

### 2.3 突破三：可拆卸镶嵌座圈 + 一体化锻造腔体（低死区与可维护性的兼得）

原设计将 V1/V2 阀座直接加工于腔体锻件，虽死区最低但不可维护。按 R-01 改为镶嵌式座圈后的实测对比：

| 方案 | 死区容积 | 潜在漏点数 | 阀座可更换 |
|---|---|---|---|
| 传统 VCR 分体连接 | 7.2 % V₀ | 6 | 是 |
| 一体化锻造（原案） | 0.53 % V₀ | 2 | **否** |
| **镶嵌座圈（定型案）** | **0.61 % V₀** | 2 | **是** |

镶嵌方案相对原案仅牺牲 0.08 % V₀ 的死区，换来阀座可现场更换，工程上完全正确。座圈锥面密封漏率 8.2×10⁻¹³ atm·cc/s，不构成新的漏点风险。

### 2.4 突破四：单调升温梯度伴热拓扑

实测沿程温度（源温 T_s = 45 °C，HCDS 工况）：

| 位置 | 设计值 | 实测 |
|---|---|---|
| 源出口 | 45.0 | 45.1 |
| 管路中段（1.8 m） | +2 °C/m → 48.6 | 48.8（2.6 °C/m） |
| V1 阀体 (120) | ≥ 55.0 | 57.3 |
| 剂量腔 (110) | ≥ 60.0 | 62.1 |
| V2 阀体 (130) | ≥ 63.0 | 64.0 |
| 至工艺腔法兰 | ≥ 65.0 | 64.5 |

红外热像全程扫描未发现局部冷点（判据：任意点温度不低于其上游最高温度）。7 天 HCDS 连续运行后拆检，腔内壁与阀座区域**无液态冷凝痕迹**，V2 下游窥视窗清洁。

### 3.3 控制逻辑序列（最终定型）

**主循环（每工艺脉冲）**

```
FOR each pulse k:
    S1  V1←开, 保持 t_fill(k)          [3~50 ms]
    S2  V1←关, 等待 t_eq                [5~20 ms]
        采样 P(t) @10kHz, 指数外推稳态 → P1, T1
    S3  V2←开, 保持 t_dose              [5~500 ms]
    S4  V2←关, 等待 t_set                [5~20 ms]
        采样 → P2, T2
        n_k = (V_eff/R)·[P1/(Z1·T1) − P2/(Z2·T2)] − n_ads(P1,P2,T)
        e_k = n_set − n_k
        t_fill(k+1) = t_fill(k) + Kp·(e_k − e_{k-1}) + Ki·e_k     [增量式 PI]
    IF (k mod N_cal == 0) AND (晶圆交换窗口可用):
        执行 IVSC → 更新 V_eff
    IF (k mod 2000 == 0) OR (换源事件):
        执行 ABS 双温标定 → 更新 n_m, ΔH_ads
END
```

**PI 参数整定结果**：Kp = 0.42，Ki = 0.18（Ziegler-Nichols 后手工回退至 60 % 增益以抑制超调）。阶跃剂量指令响应：3 个脉冲内进入 ±0.5 % 带内，无超调。

**IVSC 触发策略**：N_cal 采用自适应值——正常运行 N_cal = 500；当连续两次 IVSC 结果的相对变化 > 0.2 % 时收紧至 200；连续五次变化 < 0.05 % 时放宽至 1000。实测长程运行中平均 N_cal = 780，IVSC 累计占用晶圆交换窗口时间 < 0.4 %，不影响产能。

## 四、验证数据摘要

### 4.1 剂量重复性（T-02）

Ar 介质，P₁ = 20 Torr，t_dose = 20 ms，150 °C，连续 1000 脉冲：

| 统计量 | 值 |
|---|---|
| 剂量均值 | 8.712×10⁻⁷ mol |
| 标准差 1σ | 1.83×10⁻⁹ mol |
| **相对重复性 1σ** | **0.21 %** |
| 极差（max−min） | 1.14 % |
| 有无趋势项 | Mann-Kendall 检验 p = 0.42，无显著趋势 |

### 4.2 长程稳定性（T-03）

HCDS 介质，30 天连续运行，每 500 循环插入一组 Ar 基准脉冲（5 脉冲）比对：

| 时间 | 基准剂量偏差（相对 Day-0） | IVSC 报告 V_eff (cm³) |
|---|---|---|
| Day 0 | 0.00 % | 5.0018 |
| Day 5 | −0.09 % | 4.9871 |
| Day 10 | −0.16 % | 4.9702 |
| Day 15 | −0.22 % | 4.9563 |
| Day 20 | −0.28 % | 4.9401 |
| Day 25 | −0.33 % | 4.9268 |
| Day 30 | **−0.37 %** | 4.9134 |

注意 V_eff 本身漂移了 1.77 %，但经 IVSC 在线补偿后**实际交付剂量的漂移仅 0.37 %**——误差抑制比约 4.8×，这正是本项目的核心价值量化。

### 4.3 QCM 相关性（R-06）

TMA/H₂O ALD，160 °C，120 个数据点：

- 线性回归：m_QCM = 26.84 × n_DVPDM + 0.31（ng vs. 10⁻⁸ mol）
- **R² = 0.991**
- 残差标准差 0.42 ng（相对 1.4 %，含 QCM 自身噪声 ~1.1 %）

斜率理论值：TMA 化学吸附后每 mol 沉积 Al(CH₃)ₓ 残基，按 QCM 有效面积 1.37 cm² 与饱和覆盖度折算的理论斜率 26.1，实测 26.84，偏差 2.8 %，在 QCM 面积不确定度内。

### 4.4 颗粒（T-09）

10⁴ 次开闭循环（V1/V2 同步）后，下游 CNC 在线采样 30 min：

| 粒径档 | 计数（particle/L） |
|---|---|
| ≥ 0.1 μm | **0.34** |
| ≥ 0.2 μm | 0.07 |
| ≥ 0.3 μm | 0.00 |

## 五、遗留问题与后续演进建议

### 5.1 遗留问题

| 编号 | 问题描述 | 影响 | 当前缓解措施 |
|---|---|---|---|
| **L-1** | ABS 的 Langmuir 单层模型对**高压多层物理吸附**工况失配。TEOS @ 25 Torr 以上时拟合 R² 降至 0.91，n_ads 预测误差 > 15 % | 限制 DVPDM 在高蒸汽压有机源上的精度，剂量重复性从 0.21 % 劣化至 0.6 % | 已实现"模型适用域监测"：当拟合残差超阈值时自动回退至"Ar 基准脉冲比对"经验补偿模式（精度 ~0.8 %，可用但非最优）。BET 三参数模型已完成离线验证（R² = 0.978），未来固件升级引入 |
| **L-2** | HBr + 10 ppm H₂O 恶劣工况下失重 0.041 mg/cm²，虽未超 0.05 限值但**裕度仅 18 %**。SEM 显示 Ni-P 镀层局部出现点蚀坑（深 1.2 μm），推测为可溶性溴化物生成 | 若客户实际气源含水量控制不佳（> 20 ppm），隔膜寿命可能低于设计的 10⁶ 次 | 出厂技术条件中明确规定 HBr 工况下的气源水分限值 ≤ 10 ppm；同时在 HBr 应用中将隔膜更换周期由 10⁶ 次缩短至 5×10⁵ 次 |
| **L-3** | 180 °C 以上时压电阀关闭时间由 1.6 ms 劣化至 1.9 ms，且叠堆推力衰减约 7 % | 200 °C 高温前驱体工况下的时序裕度收窄 | 行程闭环（应变片反馈）已补偿推力衰减导致的座封应力下降；但关闭时间劣化未补偿，200 °C 工况下最小脉冲宽度提高至 8 ms |
| **L-4** | IVSC 的 C1 抽空步骤依赖工艺腔真空。若工艺腔正处于高压工步，校准需等待窗口，极端排产下可能连续 3 个 lot 无法执行校准 | 校准间隔被动拉长，误差累积 | 已实现自适应 N_cal 策略；建议后续增设独立真空支路（见 5.2 演进建议 E-2） |
| **L-5** | 参考腔 Vr* 的长期稳定性仅通过 12 个月复检保证，运行期内无冗余交叉验证手段 | Vr* 若因意外污染漂移，IVSC 将系统性失准且不可自察 | 当前依赖 12 个月计量室复检 + 年度趋势审查 |
